# AP-901 — z.object sem .nullable().optional() em campo opcional do banco [FIXTURE]

## Contexto
Coluna `nullable` no Postgres pode vir `null` explícito, não só ausente.

## Erro
Schema Zod usava `.optional()` sozinho num campo que o banco retorna como `null` — `safeParse`
falhava em produção para toda linha com o campo vazio.

## Correção
`.nullable().optional()` sempre que a coluna aceitar `NULL`.

## Why
Fixture sintética criada para o pipeline de compilação de índice de memória (spec 060). Cobre
`anti-patterns/data_and_schema`, junto de R-900/R-901/R-903 no mesmo domínio para testar o teto de
2 por domínio no conjunto selecionado.
