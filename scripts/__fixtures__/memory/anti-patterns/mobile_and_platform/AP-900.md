# AP-900 — useEffect sem array de dependências em hook de notificação [FIXTURE]

## Contexto
`useEffect` sem segundo argumento (array de dependências) reexecuta a cada render.

## Erro
Hook de agendamento de notificação local reagendava a notificação a cada re-render do componente
que o consumia, duplicando alertas no dispositivo do usuário.

## Correção
Sempre declarar o array de dependências, mesmo vazio quando o efeito só roda no mount.

## Why
Fixture sintética criada para o pipeline de compilação de índice de memória (spec 060). Cobre
`anti-patterns/mobile_and_platform`.
