# R-902 — useState em componente de lista precisa de key estável [FIXTURE]

## Rule
Listas renderizadas a partir de estado local (`useState`) usam `key` estável (id de domínio), nunca
o índice do array — reordenar/filtrar sem isso quebra o estado de inputs internos do item.

## Why
Fixture sintética criada para o pipeline de compilação de índice de memória (spec 060). Testa
seleção por domínio `react_and_ui` a partir de diff de UI.
