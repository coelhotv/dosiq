# R-900 — Coluna dropada exige migração de leitura antes do DROP [FIXTURE]

## Rule
Antes de qualquer `DROP COLUMN`, confirmar (via `information_schema.columns`) que nenhuma leitura
no código (select, tipo, Zod) ainda referencia a coluna.

## Why
Fixture sintética criada para o pipeline de compilação de índice de memória (spec 060/scripts
compile-memory-index.mjs e select-rules.mjs). Não é uma regra real do acervo.
