# R-903 — Toda tabela nova ganha comentário de propósito [FIXTURE]

## Rule
`COMMENT ON TABLE` obrigatório em toda tabela nova.

## Why
Fixture sintética (spec 060) com glob GENÉRICO (`supabase/**`, especificidade 1) de propósito —
usada para provar que R-901 (glob específico, especificidade 2) vence no desempate quando os dois
casam o mesmo caminho alterado.
