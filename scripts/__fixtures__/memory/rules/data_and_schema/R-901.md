# R-901 — ALTER TABLE em produção exige janela de manutenção [FIXTURE]

## Rule
`ALTER TABLE` em tabela com tráfego real roda fora de horário de pico, com plano de rollback
documentado no PR.

## Why
Fixture sintética criada para o pipeline de compilação de índice de memória (spec 060). Usada
junto de R-903 para testar o desempate por especificidade de glob (ambas casam
`supabase/migrations/*.sql`, mas R-901 é mais específica que o `supabase/**` de R-903).
