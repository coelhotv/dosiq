Regra é sobre DATAS de calendário, não instantes. Fix: normalizar `now` p/ meia-noite local (`parseLocalDate(formatLocalDate(now))`, sem `new Date()` por R-020) + `Math.round` + `MS_PER_DAY` nomeado; `end===hoje`→0→'vencendo'. Alertas diários/cron/janelas-N-dias comparam datas, nunca `Date.now()` em janela 24h. Latente no `Stock.jsx` original; carve-out+teste expôs (HIGH Gemini #680) -> [`anti-patterns/data_and_schema/AP-240.md`](./anti-patterns/data_and_schema/AP-240.md)

Fix: auth Supabase JWT obrigatória (401), system prompt composto NO SERVIDOR (cliente só envia `patientContext`), safety guard + rate limit server-side.
