# R-202: Role-Based Admin Access

## Context
Implementing administrative views or features that should only be accessible to specific users.

## Rule
Prefer metadata-based role checks (e.g., `user.user_metadata.role === 'admin'`) over hardcoded user IDs. Hardcoded IDs are difficult to maintain across environments (Dev/Staging/Prod) and are not scalable.

## Example
```javascript
// ✅ CORRECT
const isAdmin = user?.user_metadata?.role === 'admin';

// ❌ WRONG
const isAdmin = user?.id === 'abc-123-hardcoded-id';
```
