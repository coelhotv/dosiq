# R-272 — Dose líquida sempre via formatter core (unidade de tomada), nunca enum cru

**Classe:** rule · **Layer:** warm · **Pack:** design-ui · **Status:** active

## Regra
Qualquer superfície que renderiza dose de medicamento líquido DEVE usar o
formatter centralizado de `@dosiq/core` (`formatIntakeDose` / `formatDoseItem` /
`formatDoseHint`) com a **unidade de tomada** (`protocol.intake_unit`:
gotas|ml|UI), nunca a `dosage_unit` do medicamento (mg/ml, ui/ml).

## Por quê
`dosage_unit` é a concentração (físico do medicamento), não como o paciente
toma. Renderizar cru produz strings erradas/confusas: "10 ui/ml" no card de
histórico em vez de "10 UI"; "10000mg/ml/dia" no modo consulta. Formatter solid-only
(`formatActiveIngredientFormula`) só multiplica dose×concentração → não serve a líquidos.

## Como aplicar
- Toda query que alimenta render de dose líquida traz `intake_unit` + `units_per_ml`
  (read-path completeness, cf. [[R-267]]).
- Render via core formatter; sólido→`formatActiveIngredientFormula`,
  líquido→`formatIntakeDose`/`formatDoseHint` (decisão por `isLiquidMedicine`).
- Nunca interpolar `dosage_unit`/`intake_unit` direto na UI.
