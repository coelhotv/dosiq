# R-204: Semantic A11y Elements (Buttons)

## Context
Creating interactive elements that trigger actions (e.g., toggles, links, buttons).

## Rule
Interactive elements MUST be semantic `<button>` elements (or specialized `IconButton` components) rather than clickable `<div>` or `<span>` elements. This ensures proper keyboard navigation, screen reader support, and native browser interaction patterns (focus, active states).

## Example
```jsx
// ✅ CORRECT
<button onClick={handleClick} className="sr-btn">
  <Icon />
</button>

// ❌ WRONG
<div onClick={handleClick} style={{ cursor: 'pointer' }}>
  <Icon />
</div>
```
