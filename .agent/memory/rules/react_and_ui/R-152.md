# R-152: isComplex = mode !== 'simple' [CRITICAL — Design Personas]

**Summary:** Use binary isComplex flag for design persona bifurcation

**Applies to:** react

**Tags:** design

## Rationale

Two design personas (simple/complex) are cleaner than three. CSS handles density variation via grid responsiveness, not prop.
