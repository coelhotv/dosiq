# R-217: Logout via localStorage Cleanup (Workbox Workaround)

## Context
O service worker Workbox está registrado neste projeto (PWA). Ele intercepta requests de rede mas não tem rota configurada para `/auth/v1/logout`.

## Rule
**NUNCA usar `supabase.auth.signOut()` diretamente para logout.** Usar sempre o padrão de limpeza de localStorage:

```js
const handleLogout = async () => {
  if (!window.confirm('Deseja realmente sair?')) return
  Object.keys(localStorage)
    .filter((k) => k.startsWith('sb-'))
    .forEach((k) => localStorage.removeItem(k))
  window.location.reload()
}
```

## Por Que
Workbox intercepta `https://*.supabase.co/auth/v1/logout?scope=*` e retorna erro "No route found". O `signOut()` falha silenciosamente — o usuário permanece logado mesmo após clicar em "sair".

Isso afeta tanto `scope: 'global'` quanto `scope: 'local'`.

## Verificação
Se `supabase.auth.signOut()` for necessário (ex: invalidar sessão no servidor), envolver em try/catch e chamar o localStorage cleanup independentemente do resultado.
