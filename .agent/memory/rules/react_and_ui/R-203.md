# R-203: Semantic Versioning in Footers

## Context
Displaying the current application version in the UI (e.g., in Settings or Profile footers).

## Rule
Always use `import.meta.env.VITE_APP_VERSION` to dynamically inject the version from the build environment. Provide a hardcoded fallback to the project's canonical version (currently `3.3.0`) if the environment variable is missing.

## Example
```javascript
// ✅ CORRECT
const APP_VERSION = import.meta.env.VITE_APP_VERSION || "3.3.0";

// ❌ WRONG
const APP_VERSION = "3.2.1"; // Hardcoded and out of sync
```
