# [R-214] Branding Isolation (Marketing vs UX)

## Context
A brand's visual identity (wordmark, primary accent colors, specific typography like Comfortaa) is crucial for recognition during the entry phase (Login, Splash, Onboarding). However, these same elements can be detrimental to user experience (UX) when applied globally across a data-dense product.

## Rule
Brand-specific tokens MUST be isolated in explicit 'brand' keys within the design system. They should never overwrite or leak into global UI tokens used for general content.

## Implementation Pattern
```javascript
// ✅ CORRECT: Isolated branding
export const colors = {
  text: {
    primary: '#1a1c1e', // UI readability
    brand: '#004d45',   // Brand identity
  },
  bg: {
    screen: '#f8fafb', // UI surface
    brand: '#F0FDFB',  // Brand surface
  }
}

export const typography = {
  fontFamily: {
    regular: 'System',        // UX efficiency
    brand: 'Comfortaa-Bold',  // Brand identity
  }
}
```

## Benefits
- Maintains brand impact at critical touchpoints (Login/Splash).
- Preserves readability and information density in the logged-in experience.
- Allows for independent evolution of branding and product UX.
