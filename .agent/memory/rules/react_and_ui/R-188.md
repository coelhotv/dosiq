# [R-188] SWR Fetcher Memoization (Infinite Render Loop Prevention)

## Contexto
O `useCachedQuery` (baseado no SWR) utiliza a referência da função `fetcher` como parte da identificação da query. Se o `fetcher` for recriado a cada render (ex: definido dentro do corpo do hook sem `useCallback`), o SWR detectará uma mudança de chave e disparará um novo fetch, entrando em loop infinito.

## Regra
Todo `fetcher` passado para `useCachedQuery` ou hooks similares DEVE ser memorizado via `useCallback`.

## Exemplo ( ✅ Correto )
```javascript
const fetcher = useCallback(() => service.get(userId), [userId])
const { data } = useCachedQuery(key, fetcher)
```

## Anti-Exemplo ( ❌ Incorreto )
```javascript
// Recriado a cada render → Loop Infinito
const { data } = useCachedQuery(key, () => service.get(userId))
```
