## Regra

Todo módulo importado por função Vercel (`api/*.js`, `server/services/*.js`, `server/bot/botFactory.js`) deve ser coberto por um smoke test de import isolado em Node puro — sem JSDOM, sem browser globals.

## Por que

`validate:agent` roda em Vitest/JSDOM: `WebSocket`, `fetch`, `crypto` existem globalmente. Erros de construtor e de import de módulos serverless só aparecem em Node puro (ambiente real da Vercel Node 20). Sem esse smoke, qualquer breaking change de dep que exija um global de browser/Node 22 chega direto a prod.

## Como aplicar

1. Criar `scripts/smoke-server.mjs` importando módulos críticos do servidor
2. Adicionar step no CI: `node --version && node scripts/smoke-server.mjs` com Node 20
3. Ao adicionar novo módulo em `api/` ou `server/services/`, adicionar ao smoke
4. Ao bumpar `@supabase/supabase-js` ou libs com sub-deps de runtime, rodar smoke localmente antes do PR
