# [R-223] Mobile Button Stacking

**Context:** Telegram/Mobile Action Buttons.
**Domain:** `server/notifications`

## Rule
Prefer vertical stacking for Telegram and Mobile notification action buttons instead of horizontal arrays.

## Reasoning
- Horizontal buttons often overflow or get truncated on smaller mobile devices.
- Vertical stacking provides larger hit-targets, reducing "fat-finger" errors.
- Ensures a consistent experience across different message lengths and screen widths.

## Examples

### ✅ Correct (Vertical)
```javascript
const actions = [
  { id: 'take', label: '✅ Tomei' },
  { id: 'snooze', label: '⏰ Adiar 15min' }
];
// Rendered as vertical stack in bot/channel
```
