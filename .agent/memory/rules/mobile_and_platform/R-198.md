## Regra

`resolveChannelsForUser` só retorna `'web_push'` quando **ambas** as condições são verdadeiras:

1. `user_settings.channel_web_push_enabled === true`
2. Existe device ativo em `notification_devices` com `provider = 'webpush'`

Não inferir apenas pela existência de subscription (o usuário pode ter subscription mas ter desabilitado o canal). Não inferir apenas pela flag (o usuário pode ter flag `true` mas subscription expirada).

No app mobile nativo: nunca tentar criar subscription PWA — apenas exibir status informativo ("Configure pelo navegador") baseado na flag do banco.
