## Regra

No app mobile, notificações acessam-se por **Perfil → Notificações** (1 card único com badge). Não criar cards paralelos para Preferências, Central de Avisos e Telegram no mesmo nível do Perfil.

Hierarquia obrigatória:
```
Perfil
└── Notificações [badge]
     ├── Avisos (Inbox) → gear → Preferências
     └── Preferências → canal Telegram
```

Telegram é **subfluxo** de Preferências, não seção autônoma do Perfil.

## Origem

ADR-035 / Wave N2 — Sprint 2.4. Antes da N2, o Perfil tinha 3 cards concorrentes (Preferências, Central de Avisos, Bot Telegram) gerando confusão sobre onde gerenciar notificações.
