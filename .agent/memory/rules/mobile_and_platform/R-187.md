# [R-187] Dynamic User-Specific Cache Keys (Mobile Persistence Security)

## Contexto
Em PWAs ou Apps Nativos que utilizam persistência offline (AsyncStorage ou LocalStorage), o uso de chaves estáticas pode causar vazamento de dados entre usuários diferentes que utilizam o mesmo dispositivo/navegador.

## Regra
Toda chave de persistência de dados sensíveis ou específicos do usuário DEVE ser construída dinamicamente incluindo o `userId`.

## Exemplo ( ✅ Correto )
```javascript
const CACHE_KEY = `@dosiq/notifications:${userId}`
await AsyncStorage.setItem(CACHE_KEY, data)
```

## Anti-Exemplo ( ❌ Incorreto )
```javascript
const CACHE_KEY = '@dosiq/notifications-snapshot'
await AsyncStorage.setItem(CACHE_KEY, data) // Erro: Se outro usuário logar, verá o cache do anterior.
```
