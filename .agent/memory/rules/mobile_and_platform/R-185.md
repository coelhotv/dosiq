# R-185: Redundant UI-Level Temporal Filtering

Dados temporais (que possuem validade baseada em data) **DEVEM** ser re-filtrados na camada de UI (hooks/memos), mesmo que tenham sido filtrados na query do banco/serviço.

## Por que?
Aplicativos móveis dependem de cache offline (AsyncStorage Snapshots). Um snapshot capturado ontem pode conter protocolos que expiraram à meia-noite. Sem uma filtragem redundante no momento do render, o usuário verá "fantasmas" de tratamentos antigos até que ocorra um refresh online.

## Como Aplicar
No hook que consome os dados do cache:

```javascript
const filteredData = useMemo(() => {
  if (!data) return null;
  const today = getTodayLocal();
  // ✅ SEMPRE aplicar o filtro de validade novamente aqui
  return data.filter(item => isProtocolActiveOnDate(item, today));
}, [data]);
```
