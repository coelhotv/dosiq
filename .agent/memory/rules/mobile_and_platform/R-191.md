# R-191 — Semantic Dose Notification Grouping

Agrupar doses do mesmo minuto em blocos semânticos via `partitionDoses()` antes de disparar notificações.
**Nunca enviar 1 push por protocolo** — envia 1 push por bloco semântico.

## Algoritmo partitionDoses() — 9 Cenários

| Bloco | Condição | Kind |
|-------|----------|------|
| `by_plan` | ≥2 doses do mesmo `treatment_plan_id` | `dose_reminder_by_plan` |
| `misc` | ≥2 doses sem plano (ou com planos únicos > 3) | `dose_reminder_misc` |
| `individual` | 1 dose (com ou sem plano) | `dose_reminder` |

```
Cenário A: N doses sem plano (N≥2) → 1 bloco misc
Cenário B: N doses mesmo plano (N≥2) → 1 bloco by_plan
Cenário C: plano A(≥2) + avulsas(≥2) → by_plan + misc
Cenário D: plano A(≥2) + plano B(≥2) → 2× by_plan
Cenário E: plano A(≥2) + plano B(≥2) + avulsas(≥2) → 2× by_plan + 1 misc
Cenário F: plano A(≥2) + plano B(≥2) + 1 avulsa → 2× by_plan + 1 individual
Cenário G: plano A(1) + plano B(1) (≤3 únicos) → 2× individual (1 por plano)
Cenário H: 1 dose com plano → 1 individual
Cenário I: 1 dose sem plano → 1 individual
```

## Dispatcher call por bloco

```js
// by_plan
dispatcher.dispatch({ userId, kind: 'dose_reminder_by_plan', data: {
  planId, planName, doses, protocolIds, scheduledTime, hour
}})

// misc
dispatcher.dispatch({ userId, kind: 'dose_reminder_misc', data: {
  doses, protocolIds, scheduledTime, hour
}})

// individual (existente)
dispatcher.dispatch({ userId, kind: 'dose_reminder', data: { protocolId, ... }})
```

## Localização canônica

- `server/bot/utils/partitionDoses.js` — algoritmo puro (testável isoladamente)
- `server/bot/tasks.js` — `checkRemindersViaDispatcher()` coleta e chama partitionDoses
- `server/notifications/channels/telegramChannel.js` — formatMessage detecta kind

**Why:** 1 push por protocolo cria spam e não contextualiza tratamento.
Blocos semânticos reduzem notificações, melhoram UX e permitem ações em lote.

**Source:** Sprint N1.1 — Wave N1 Notifications Revamp (2026-04-25)
