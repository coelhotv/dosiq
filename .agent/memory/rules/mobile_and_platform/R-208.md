# [R-208] Adherence Report Scheduling

O relatório diário de adesão deve ser agendado para as 23:00 (definido pela constante `ADHERENCE_REPORT_TIME`) para garantir o fechamento completo do dia, desacoplado do horário do boletim matinal (digest) configurado pelo usuário.

## Contexto
Anteriormente, o relatório diário de adesão era disparado junto com o boletim matinal (digest), o que causava confusão (receber o fechamento do dia anterior logo cedo) e dependência de configuração do usuário.

## Detalhes
- **Arquivo**: `server/bot/tasks.js`
- **Constante**: `ADHERENCE_REPORT_TIME = '23:00'`
- **Comportamento**: O dispatcher deve ignorar o `digest_time` para o kind `daily_adherence_report` e utilizar esta constante global.

## Exemplos

### ✅ Correto (server/bot/tasks.js)
```javascript
export const ADHERENCE_REPORT_TIME = '23:00';

// No dispatcher:
if (kind === 'daily_adherence_report') {
  targetTime = ADHERENCE_REPORT_TIME;
}
```

### ❌ Incorreto
```javascript
// Usar o digest_time do usuário para o relatório de adesão
const targetTime = userSettings.digest_time || '08:00'; 
```
