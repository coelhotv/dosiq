# R-233 — Bottom sheet mobile (Modal RN) deve usar pattern unificado Android-safe

**Regra**: todo `<Modal>` que renderiza bottom sheet em RN no Dosiq mobile DEVE incluir:

1. `statusBarTranslucent` prop no `<Modal>` (Android cobre window stack inteiro)
2. View spacer `{ height: StatusBar.currentHeight ?? 0 }` no topo (Android only, dentro do `root`)
3. `SafeAreaView edges={['bottom']}` no container do sheet (gesture bar moderno)

**Why**: ver [[AP-165]]. Sem isso, Android API 24 não cobre topo (overlay truncado) + inputs do form parent vazam por cima + bottom tab bar renderiza acima dos botões do sheet.

**How to apply**:

```jsx
import { View, Modal, Pressable, StyleSheet, Platform, StatusBar } from 'react-native'
import { SafeAreaView } from 'react-native-safe-area-context'

<Modal
  visible={open}
  transparent
  animationType="slide"
  onRequestClose={onClose}
  statusBarTranslucent
>
  <View style={styles.root}>
    {Platform.OS === 'android' ? (
      <View style={{ height: StatusBar.currentHeight ?? 0 }} />
    ) : null}
    <Pressable style={styles.backdrop} onPress={onClose} />
    <SafeAreaView edges={['bottom']} style={styles.sheet}>
      {/* conteúdo */}
    </SafeAreaView>
  </View>
</Modal>
```

**Exceção**: Modal iOS-only (Android usa picker imperativo, ex: TimeSchedulePicker) não precisa do pattern Android — mas inclua-lo não custa nada e protege futura mudança.
