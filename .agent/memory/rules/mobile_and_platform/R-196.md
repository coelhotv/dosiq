## Regra

Ao implementar quiet hours, verificar se a janela cruza a meia-noite:

```js
if (s <= e) {
  // Janela normal: ex. 13:00 → 15:00
  return cur >= s && cur < e
} else {
  // Cross-midnight: ex. 22:00 → 07:00
  return cur >= s || cur < e
}
```

- `start = end` → considerar como janela vazia (não suprime)
- `start = null || end = null` → quiet hours desativados (não suprime)
- Limiar de `start` é **inclusive**; limiar de `end` é **exclusive**
