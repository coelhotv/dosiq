# [R-209] JS Stack for Android 7 Navigation Stability

## Context
Android 7 (API 24) devices using `react-native-screens` 4.x frequently crash with `java.lang.IndexOutOfBoundsException: getChildDrawingOrder()` when using `createNativeStackNavigator`. This is due to a native drawing sync bug in `ScreenStack`.

## Rule
In navigation flows where rapid back-navigation or deep nesting occurs on legacy Android (API 24/25), substitute `createNativeStackNavigator` with the JS-based `createStackNavigator` from `@react-navigation/stack`.

## Rationale
- Contorns the `react-native-screens` native drawing bug.
- JS-based transitions are slightly slower (~10-20ms) but stable.
- Essential for maintaining legacy hardware support (Dosiq Persona: "Dona Maria" devices).

## Examples
### ✅ CORRECT (Stable on Android 7)
```jsx
import { createStackNavigator } from '@react-navigation/stack'
const Stack = createStackNavigator()

export default function ProfileStack() {
  return (
    <Stack.Navigator>
      <Stack.Screen name="Profile" component={ProfileScreen} />
    </Stack.Navigator>
  )
}
```

### ❌ WRONG (Crashes on Android 7)
```jsx
import { createNativeStackNavigator } from '@react-navigation/native-stack'
const Stack = createNativeStackNavigator()
```
