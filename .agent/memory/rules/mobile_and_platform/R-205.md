# [R-205] Mobile Push Notifications MUST be Plain Text

## Context
Mobile push notifications (iOS via APNs and Android via FCM/Expo) are rendered as plain text by the operating system. Unlike Telegram or certain web inbox implementations, they do NOT support MarkdownV2 or similar formatting languages.

## Rule
The `pushBody` field (and any content destined exclusively for mobile push channels) MUST be plain text.

1. **NO Escaping**: Do NOT use backslash escapes for reserved characters (e.g., `\!`, `\.`, `\(`).
2. **NO Markdown**: Do NOT use bold (`**`), italics (`_`), or other Markdown markers unless they are intended to be seen literally (which is usually not the case).
3. **Clean Interpolation**: When reusing storytelling strings or greetings that contain Markdown escapes, ensure they are cleaned (e.g., `.replace(/\\/g, '')`) before being assigned to `pushBody`.

## Reason
Providing escaped strings to mobile push channels results in visible backslashes (e.g., "Bom dia\!") which looks unprofessional and degrades the user experience.

## Examples

### ❌ Incorrect
```javascript
const pushBody = "Bom dia\\! Sua adesão de ontem foi 100%\\.";
```

### ✅ Correct
```javascript
const pushBody = "Bom dia! Sua adesão de ontem foi 100%.";
```
