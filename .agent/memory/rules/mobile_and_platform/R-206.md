# [R-206] L3 Gate Validation

**Status:** active · **Layer:** warm · **Domain:** mobile_and_platform
**Reconciliado:** 2026-05-31 (D5 — detail file recriado a partir do índice; arquivo original ausente/perdido)

## Regra
Toda notificação enviada ao `dispatchNotification` (L3) DEVE ter seu `kind` validado contra o
enum central ANTES de qualquer processamento de payload. Validação de entrada na porta do
dispatcher previne payloads malformados e falhas silenciosas downstream.
