# [R-207] Notification Deeplink Decoupling

**Status:** active · **Layer:** warm · **Domain:** mobile_and_platform
**Reconciliado:** 2026-05-31 (D5 — detail file recriado a partir do índice; arquivo original ausente/perdido)

## Regra
A resolução de URLs de navegação (deeplinks) DEVE ser isolada da lógica de construção de
mensagens (L2), preferencialmente em mapas ou funções auxiliares dedicadas. Acoplar deeplink
à formatação de mensagem espalha conhecimento de rotas pela camada de apresentação.
