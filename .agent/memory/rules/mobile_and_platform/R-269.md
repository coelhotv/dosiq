## Regra

Em telas dentro de um navigator com bottom tab bar (React Navigation `BottomTabNavigator`), usar `SafeAreaView` com `edges={['top']}` APENAS. Nunca incluir `'bottom'` nas edges.

## Por quê

React Navigation já aplica o inset inferior necessário para o tab bar internamente. Adicionar `edges={['bottom']}` na `SafeAreaView` da tela duplica o espaçamento — cria "caixa suspensa" (conteúdo flutua com gap vazio antes do tab bar). O padrão do projeto é `ScreenContainer`, que já usa `edges={['top']}`.

## Como aplicar

```jsx
// ERRADO — double inset:
<SafeAreaView edges={['top', 'bottom']} style={styles.container}>

// CORRETO — só top; bottom é do React Navigation:
<SafeAreaView edges={['top']} style={styles.container}>
```

Sintoma: conteúdo "suspenso" com gap vazio antes do tab bar. Fix: remover 'bottom' das edges.

Exceção: telas modais full-screen fora do tab navigator podem usar edges={['top', 'bottom']} normalmente.
