# R-186: Accordion Toggle Integrity

Ao implementar accordions que iniciam **abertos por padrão** via lógica de negação (ex: `isExpanded !== false`), o handler de toggle **DEVE** normalizar o estado atual antes de inverter.

## Por que?
Se o estado inicial é um objeto vazio `{}`, o valor de `expanded[id]` será `undefined`. Usar `!prev[id]` resultará em `true` (mantendo o accordion aberto), exigindo um segundo toque para finalmente chegar em `false` (fechar).

## Como Aplicar

```javascript
// ❌ ERRADO: Requer 2 taps se o estado inicial for aberto por padrão
setExpanded(prev => ({ ...prev, [id]: !prev[id] }));

// ✅ CORRETO: Normaliza o estado implícito primeiro
setExpanded(prev => {
  const isCurrentlyExpanded = prev[id] !== false; // Considera undefined como true
  return { ...prev, [id]: !isCurrentlyExpanded };
});
```
