# R-177: Always use ~/git/dosiq/ as working path

**Daqui para frente, usar o caminho `~/git/dosiq/` para o projeto.**

Os agentes e sessões DEVFLOW DEVEM usar primariamente o caminho `~/git/dosiq/` para interagir com este projeto.

**Histórico:** até 2026-05-24 o projeto vivia no iCloud (`~/Library/Mobile Documents/com~apple~CloudDocs/git/dosiq/`, acessado via symlink `~/git-icloud/dosiq/`). Em 2026-05-24 foi movido para fora do iCloud para `~/git/dosiq/`, eliminando na raiz os problemas de Watchman/Metro/EAS (ver R-161, AP-H07 — resolvidos). O gitdir continua externo em `~/local_git/dosiq/.git` (arquitetura bridge).

Evite os caminhos antigos (`~/git-icloud/dosiq/`, `~/Library/Mobile Documents/...`).
