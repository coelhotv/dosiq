# R-221 — SQP (Standard Quality Protocol) [CRITICAL]

## Rule
Complex projects divided into "Gates" (e.g., Notification Architecture Consolidation) must follow the Standard Quality Protocol:

1. **Branch Naming**: All work must occur in branches named `feat/gate-{id}-{slug}`.
2. **Hard Stop**: Agents must STOP and request explicit human validation/approval BEFORE any commit or push.
3. **Zero Lint Regression**: No new lint warnings or errors are allowed. Any regression must be fixed before proceeding.
4. **CI Validation**: `npm run validate:agent` must be executed and pass before PR submission.
5. **Approval Cycle**:
   - Work starts -> Implementation -> **Hard Stop (Human Review)**.
   - Human approves -> Commit -> Push -> Create PR.
   - PR Review Fixes -> Approval -> Merge -> Finalize Gate.

## Why
Prevents architectural drift, minimizes review burden, and ensures high quality in foundational changes that span multiple files and layers.

## Context
This protocol was established during the Gate 1 of the Notification Architecture Consolidation to harden the transition from legacy formatters to centralized payloads.
