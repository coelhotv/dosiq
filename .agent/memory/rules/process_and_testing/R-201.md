# R-201: Secure Token Generation (Crypto API)

## Context
When generating security tokens, temporary codes, or unique identifiers in the frontend that require cryptographic strength.

## Rule
ALWAYS use `window.crypto.getRandomValues()` (or a high-level wrapper) to generate random values for security-sensitive tokens. NEVER use `Math.random()`, as it is not cryptographically secure and can be predictable.

## Example
```javascript
// ✅ CORRECT
const array = new Uint32Array(1);
window.crypto.getRandomValues(array);
const token = array[0].toString(16);

// ❌ WRONG
const token = Math.random().toString(36).substring(2);
```
