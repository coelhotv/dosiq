# R-243 — Structured Portuguese Changelog Entries

## Rule
Every code-changing PR must add a Portuguese changelog entry under `CHANGELOG.md` `[Unreleased]` before PR creation.

The entry must include:
- affected platform section: Web/PWA, Mobile, Shared/Core, or Backend/Infra;
- change category: Added, Changed, Fixed, Security, Deprecated, Removed, or Process;
- SemVer impact from R-242;
- concise user-facing description in Portuguese;
- PR placeholder or PR number when available.

Do not bypass SQP by writing ad hoc changelog text. Use the project template in `docs/standards/CHANGELOG_AND_RELEASES.md`.

## Why
Portuguese changelog entries are the source material for release notes, App Store notes, Play Store notes, and user-facing support history.
