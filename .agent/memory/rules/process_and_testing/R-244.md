# R-244 — Mobile Store Notes Derive from Changelog

## Rule
Before any App Store or Play Store submission, mobile release notes must be derived from structured Portuguese entries already present in `CHANGELOG.md`.

Mobile release entries must be usable for:
- App Store "What's New" text;
- Play Store release notes;
- support/debug traceability from store version to PRs.

If a mobile PR cannot produce store-facing notes because it is internal-only, mark the changelog entry as `no-user-impact` and include a short Portuguese justification.

## Why
Apple and Google require release descriptions for new versions. Deriving notes from changelog entries prevents last-minute reconstruction from PR history.
