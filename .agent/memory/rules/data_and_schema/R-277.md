# R-277 — cleanFloat em matemática de concentração

## Regra

Toda multiplicação/divisão de concentração — reexibir `amount = razão × volume` e
persistir `razão = amount ÷ denominador` (FR-031/ADR-066) — DEVE passar pelo helper
`cleanFloat` do `@dosiq/core` **antes de exibir OU persistir**:

```js
export const cleanFloat = (value) => {
  const n = Number(value)
  return Number.isFinite(n) ? parseFloat(n.toPrecision(12)) : n
}
```

## Por quê

`formatNumberPtBR` faz `String(Number(x))` puro — **não arredonda**. A dízima de
ponto flutuante do JS (`0.1 + 0.2 === 0.30000000000000004`) vaza inteira pro chip/
card e é gravada no banco. `toPrecision(12)` corta o ruído de ~15-17 dígitos
mantendo precisão real; `parseFloat` remove zeros à direita. Ver [[AP-226]].

## Onde aplicar (call sites B3)

- `doseUnit.js`: `formatConcentration` (`ratio*vol`), `formatConcentrationLabel`
- web `_medicineFormUtils.js`: `getInitialFormData` (reexibe), `buildMedicinePayload` (persiste)
- mobile `MedicineFormScreen.jsx`: `initialValues` (reexibe), `handleSubmit` (persiste)
- web `MedicineFormDosageInfo.jsx`: preview da razão

## Como aplicar

Novo cálculo de concentração/dose → envolver o resultado em `cleanFloat()` no ponto
de saída (display) e no payload (persist). Não-finito passa direto (deixa a validação
Zod decidir). Família numérica [[R-270]] / [[R-276]].
