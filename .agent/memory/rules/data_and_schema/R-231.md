# [R-231] Factory pattern para repositórios CRUD compartilhados web↔mobile

## Definição
Toda nova entidade que precisa de CRUD em **web E mobile** deve ser implementada como **factory** parametrizada em `@dosiq/core/repositories/`, e NÃO duplicada em cada app.

A factory recebe via DI:
- `client` — instância Supabase específica da plataforma (web `@shared/utils/supabase`, mobile `nativeSupabaseClient`)
- `getUserId` — função async resolvendo user_id da sessão (cada plataforma tem cache/coalescência distintos)
- `listSelect` / `detailSelect` — fragments select específicos por plataforma (web inclui stock/purchases, mobile inclui protocols(id))
- `listTransform` / `detailTransform` — pós-processamento (ex: `avg_price` no web)

Validação Zod (`validateXCreate/Update`) é **canônica e não parametrizável** — vem de `@dosiq/core/schemas`.

## Por que
- Cópia ad-hoc entre apps gera drift silencioso (schema validation, error format, ordem de chamadas Supabase). Web e mobile divergem mesmo quando deveriam ser idênticos.
- Factory garante que payload de `insert/update`, formato de erro, e contrato de validação são **idênticos** entre plataformas, com diferenças explícitas apenas via parâmetros.
- Permite parity tests com mocked client: 1 suite cobre os 2 apps.

## Aplicação
- **Fase 1 (Medicamentos)** — `createMedicineRepository` em `packages/core/src/repositories/`. Web e mobile reduziram CRUD para ~30 LOC cada (preset config).
- 19 parity tests em `packages/core/src/repositories/__tests__/createMedicineRepository.test.js` rodam via vitest do web (configurado para varrer `packages/core/**/*.test.js`).
- Fase 2 (Protocolos) deve seguir o mesmo padrão.

## Contrato mínimo
```javascript
export function createXRepository({
  client,                  // obrigatório
  getUserId,               // obrigatório, async () => string
  listSelect = '*',
  detailSelect = '*',
  listTransform = (rows) => rows,
  detailTransform = (row) => row,
}) {
  // ... CRUD canônico com Zod centralizado
}
```

## Anti-pattern relacionado
- Service ad-hoc duplicado por plataforma com schema validation copy-paste — leva a drift.
