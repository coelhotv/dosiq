# R-313 — Predicado de domínio tem UMA definição, e um gate por grep de saída que a protege

**Layer:** warm · **Packs:** data_and_schema, process_and_testing
**Origem:** spec 064 (SC-004) · PR #808 (2026-08-21)
**Família:** [[R-299]] §3 (fato datado) · [[AP-290]] (gate que apodrece) · [[AP-333]] (duas implementações)

## A regra

Quando uma pergunta de domínio ("este tratamento vale nesta data?", "esta compra conta neste mês?")
é respondida em **mais de um lugar**, ela deixa de ser regra e vira folclore: cada sítio esquece um
eixo diferente. No 064 eram 8 sítios de vigência, cada um com um pedaço: um só `p.active`, outro
`active !== false`, outro `active && isProtocolInPeriod`, e a query com os três eixos.

1. **Uma função exportada no core** responde a pergunta. Nome do domínio, não do consumidor
   (`isProtocolVigentOn`, não `filterStockProtocols`).
2. **Os consumidores chamam — nunca reescrevem.** Inclusive quando "é só um `&& p.active`".
3. **Filtro SQL equivalente é permitido, mas rotulado** como redundante-por-performance, com
   comentário apontando o predicado canônico. Query não é predicado reusável; sem o rótulo, o
   próximo agente "consolida" para o lado errado e a query vira o sítio N+1.
4. **Um gate por grep de saída** reprova o padrão solto no escopo declarado — não um teste, um
   script no `lint`. Teste prova o predicado; só o grep prova a **ausência** de reimplementação.

## O gate (forma canônica)

Precedente: `scripts/unit-label-gate.sh` (053) → `scripts/vigency-single-source.sh` (064).

- Escopo **declarado no cabeçalho** do script; ampliar escopo é decisão de spec, não do gate.
- Liberação por **marcador inline** com justificativa (`vigency-gate: ok — <motivo>`), varrendo até
  2 linhas acima. **Nunca âncora por `file:line`**: ela envelhece no primeiro commit que insere uma
  linha acima e o gate passa a reprovar exatamente a linha que existia para permitir (foi o que
  deixou a `main` vermelha por 5 dias no `unit-label-gate.sh`).
- Dívida conhecida entra em array **nomeado** (`PENDING_NNN`) com o porquê e a task que a resolve —
  é dívida declarada, não liberação.
- **Plugado no `lint`** (`lint:<nome>`), como o precedente. Gate que não roda apodrece ([[AP-290]]).
- **Teste negativo obrigatório na entrega:** introduzir uma violação de mentira e conferir que o
  script REPROVA. Gate verde nunca executado contra violação real não é gate.
