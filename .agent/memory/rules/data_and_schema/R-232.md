# [R-232] Zod 4 — locale PT-BR + customError friendly via `z.config()` global

## Definição
Toda app que consome `@dosiq/core` recebe automaticamente o locale Zod PT-BR + `customError` "Dona Maria friendly" via side-effect import de `./zodSetup.js`. NÃO duplicar `errorMap` por schema.

Localizar mensagens deve ser **global**, não por schema. Schemas só devem sobrescrever quando regra de negócio exige texto diferente do padrão (ex: "máximo 200 caracteres" — informação útil específica, não jargão).

## Padrão
```javascript
// packages/core/src/zodSetup.js
import { z } from 'zod'
import pt from 'zod/v4/locales/pt'

function friendlyMessage(issue) {
  switch (issue.code) {
    case 'invalid_type':
      if (issue.input === undefined || issue.input === null || issue.input === '')
        return 'Este campo é obrigatório'
      if (issue.expected === 'number') return 'Use apenas números'
      return 'Valor inválido'
    case 'too_small':
      if (issue.origin === 'string')
        return issue.minimum === 1
          ? 'Este campo é obrigatório'
          : `Use pelo menos ${issue.minimum} caracteres`
      if (issue.origin === 'number')
        return issue.minimum === 0
          ? 'O valor deve ser maior que zero'
          : `O valor deve ser maior ou igual a ${issue.minimum}`
    // ... demais casos
  }
}
const ptLocale = pt().localeError
z.config({ customError: (issue) => friendlyMessage(issue) || ptLocale(issue) })
```

Side-effect aplicado via `packages/core/src/index.js`:
```javascript
import './zodSetup.js'  // primeiro import
```

## Quando sobrescrever no schema
Apenas quando a regra dá info útil:
```javascript
name: z.string().min(2, 'O nome precisa de pelo menos 2 caracteres').max(200, 'O nome pode ter no máximo 200 caracteres')
```

Não sobrescrever mensagens default (`invalid_type`, `too_small` genérico) — deixar o customError global resolver.

## Cuidados
- `z.coerce.number()` deve ser usado para campos numéricos vindos de form HTML/RN TextInput (sempre string). Sem `coerce`, todo blur emite `invalid_type`.
- Jest mobile: adicionar `zod` a `transformIgnorePatterns` (zod 4 locales são ESM).

## Aplicação
- Fase 1 M1.2 — implementado em `packages/core/src/zodSetup.js`. Validado em iOS + Android API 24 com usuária persona "Dona Maria".
