# ADR-063 — Sincronização de contatos via Brevo API (REST) para régua de ativação

**Status:** proposed · **Origem:** Épico 026 (activation-strategy), planning 2026-06-07 · **Layer:** warm

## Contexto
A régua de e-mails de ativação precisa manter contatos sincronizados num provedor de
marketing automation. Opções: webhook por evento vs. sincronização em lote via cron.

## Decisão
Usar **Brevo API (REST — Marketing Automation)** com rotina de sincronização de contatos
disparada por **cron diário** (uma chamada em lote), não por evento.

## Consequências
- Reduz tráfego e risco de timeout na Vercel (Hobby; uma chamada agendada vs. N por evento).
- `server/utils/brevoService.js` (helper) + integração no cron (spec 026 T003/T004).
- Trade-off: latência de sincronização = até 24h (aceitável p/ régua de ativação).
