# ADR-069 — Arquitetura do revisor IA independente (RC6) pós-sunset do Gemini

**Status**: accepted (PO, 2026-07-16 — T001 arbitrou as 3 divergências script↔ADR; ver §Arbitragem)
**Data**: 2026-06-15
**Spec**: 034-gemini-sunset
**Ceremonies**: RC3 (eng) + RC-SEC (security)

## Contexto

`gemini-code-assist[bot]` (revisor independente dos PRs) será descontinuado ~07/2026. Precisa de substituto que preserve independência + presença no PR + assíncrono + robustez adversarial, a custo marginal ~$0, sem reintroduzir os riscos que motivaram a recusa anterior de revisor IA (independência fraca, ruído, custo) e sem abrir vetor de segurança.

## Decisão

Revisor independente **RC6** (`/devflow ai-review` / `rtk ai-review <PR#>`) com a arquitetura:

1. **Processo fresco, sandbox SEM ferramentas** (texto→JSON). Não recebe histórico/contexto do coder; só diff + catálogos R/AP. `--dangerously-skip-permissions` é aceitável **somente** porque o processo não tem tool-access (sem shell/file/MCP) — resolve SC-SEC1 (prompt-injection→execução sobre diff não-confiável).
2. **Motores** (revisado T001, 2026-07-16): `agy -p` (Gemini 3.1 Pro) **primário** — quota OAuth extensa (semanal + 5h) E diversidade de vendor (o fallback claude é a mesma família do agente autor: independência de contexto ≠ independência de viés). `claude -p` (Sonnet) = pass B de domínio em Tier 2. `/code-review` local (low/medium, nunca ultra como rotina) = pass extra opcional. **Codex = reserva** para PR excepcional apenas (plano Go, quota baixa). Quota OAuth → custo marginal ~$0. Sem Ollama, sem API metered.
3. **No-autofix** — RC6 só sinaliza (autofix reintroduziria viés de autor). Coder corrige via RC5/check-review e re-roda.
4. **Publica comentários inline via `gh api` (stdin) com degradação automática para PR-level** — o retry descarta comentário rejeitado (linha fora do diff) um a um até, no pior caso, sobrar review body-only, que é exatamente o PR-level. *(Revisado no T001: a versão original exigia PR-level no MVP por medo do drift de posição — DIV-2; a implementação mitigou o risco e o ADR cedeu.)* Nunca shell-interp do output (SC-SEC3).
5. **Grava só `events.jsonl`** (`ai_review_complete`), nunca `state.json` do projeto — preserva independência e evita corrida (EM2).
6. **Enforcement soft** via `ai-review-gate.yml`: `pull_request` (sem `pull_request_target` — SC-SEC4), SEM LLM, lê severidade do payload (não só presença — SC-SEC2), token least-priv, check neutro/aviso (não bloqueia merge; humano R-060 decide).
7. **Fail-open** com aviso visível se motores indisponíveis (FR-008 / Constituição IX).

## Alternativas rejeitadas

- Revisor com tool-access + skip-permissions → vetor de execução via prompt-injection (SC-SEC1). Rejeitado.
- Reusar `gemini-review.yml` para postar inline → ele só lê; postar inline é frágil (drift de posição). PR-level no MVP.
- Hard-block no gate → escolhido soft (decisão PO NC1; alinha "gate = disciplina de processo").
- API metered em CI → custo; OAuth local mantém $0 e por isso RC6 roda local (não CI).

## Consequências

- (+) Independência real a custo ~$0; presença no PR; não-bypass silencioso (aviso visível).
- (−) Enforcement depende de disciplina (gate soft); quota OAuth finita (mitigar: só PR aberto, diff-scoped).
- Trigger: manual + git hook `post-push` (NC2). Obrigatório Tier 1+ por disciplina (NC3).

## Arbitragem T001 (2026-07-16) — 3 divergências script↔ADR

O script `ai-review.sh` (repo devflow, `9b83c33`+ajustes) foi escrito com o ADR em `proposed` e divergia em 3 pontos (ver `plans/specs/034-gemini-sunset/analysis.md` §3):

- **DIV-1 (🔴 SC-SEC1)** — script rodava reviewer com tool-access. **Script cedeu**: `claude --tools "" --strict-mcp-config` (zero built-ins, zero MCP, prompt via stdin); `agy --sandbox --mode plan` (agy não tem flag no-tools explícita — verificado 2026-07-16; sandbox+plan é o máximo disponível, limitação documentada no script).
- **DIV-2 (inline vs PR-level)** — **ADR cedeu** (§ Decisão 4): o retry com degradação já mitiga o drift de posição que motivava o PR-level MVP.
- **DIV-3 (state.json vs events.jsonl)** — **Script cedeu**: `--post` agora appenda `ai_review_complete` em `.agent/memory/events.jsonl` + journal (ambos append-only); state.json é lido só para o label do sprint, nunca escrito.

**KPI do T050/T051** (adendo): medir o L2 por **caminhos não-pretendidos apontados** (a capacidade que o RC5 não tem), não por contagem de críticos — senão o L2 será aposentado pelo motivo errado (evidência: #749, RC5 achou o crítico; o revisor externo achou a lacuna de cobertura).
