# ADR-064 — Persistência local de descarte de nudge com chave composta `nudge_id:version`

**Status:** proposed · **Origem:** Épico 026 (activation-strategy), planning 2026-06-07 · **Layer:** warm

## Contexto
O descarte (dismiss) de um nudge de ativação deve ocultá-lo instantaneamente e persistir,
inclusive offline. Precisa de um mecanismo para **reexibir** um nudge quando seu conteúdo
muda (reset de descarte) sem apagar o histórico de outros.

## Decisão
Salvar o estado de descarte **localmente** (`AsyncStorage` mobile / `localStorage` web),
com **chave composta `nudge_id:version`**. A coluna `version integer` do nudge controla o
reset: incrementar a versão invalida o descarte anterior (chave nova) → nudge reaparece.

## Consequências
- Carregamento instantâneo offline-first (Zero-Network na leitura de descarte).
- Versionamento de nudge = reset de descarte sem migração nem limpeza de storage.
- Trade-off: descarte não sincroniza entre devices (aceitável; é preferência efêmera de UI).
- Edge: descarte offline sincroniza quando online (spec 026 edge-case §101).
