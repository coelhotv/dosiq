# ADR-048 — Modelo `dose_instances` (schedule-anchored)

## Status
**ACCEPTED** (2026-05-28 — promovido no planning da Fase 2; Fase 1/tz mergeada #597+#598 destrava o pré-requisito ADR-049)

## Refinamentos ratificados no planning Fase 2
- **Enum frequency com acento** (G3): casar `'diário'`/`'quando_necessário'` exato (CHECK real do DB confirmado via list_tables). Gerador pula `'quando_necessário'` (PRN).
- **`tolerance_minutes int DEFAULT 120`** por instância (janela dinâmica metade-intervalo, cap 2h — §6 master plan).
- **Status enum:** `pending|taken|missed|skipped_paused|skipped_user`.
- **Motor:** `server/bot/tasks.js` (`generateDoseInstances` via `scheduleTask`) + high-water-mark `generated_through` + rede lazy `ensureInstancesUpTo`. Reusa `isProtocolActiveOnDate`/`FREQUENCY_MATCHERS` (core).
- **Idempotência:** `UNIQUE(protocol_id, scheduled_for)` + `ON CONFLICT DO NOTHING`. Wipe cirúrgico: `status='pending' AND scheduled_for > now()`.
- **RLS/grants** obrigatórios (CLAUDE.md template). Motor roda service_role → scoping `user_id` explícito (R-042).
- **G1** (injeção de tz): motor lê `user_settings.timezone` por usuário ao gerar `scheduled_for`. Client (dashboard/adesão) injeta tz na Fase 3/4.

## Contexto

Ver [MASTER_PLAN_REFACTOR_DOSE_INSTANCE.md](../../../../plans/dose_instances_refactor/MASTER_PLAN_REFACTOR_DOSE_INSTANCE.md). `medicine_logs` não tem âncora de schedule (só `taken_at`). Adesão infere o slot via janela ±2h. Bug da meia-noite é o sintoma; raiz é o modelo inferencial.

## Decisão (resumo — detalhe na Fase 2)

Tabela `dose_instances` materializa ocorrências (status `pending|taken|missed|skipped_paused|skipped_user`, `tolerance_minutes` dinâmico, `UNIQUE(protocol_id, scheduled_for)`). Motor de geração no `server/bot/scheduler.js` (high-water-mark + rede lazy). `medicine_logs.dose_instance_id` ancora a tomada. Rollup mensal pra retenção. Janela de tolerância dinâmica (metade-intervalo, cap 2h).

## Dependência

**Bloqueado por ADR-049** (core tz-aware) — `scheduled_for` é instante absoluto e exige fuso correto antes da geração.
