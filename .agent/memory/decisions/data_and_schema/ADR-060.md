# ADR-060 — `biomarkers_log` genérico + adapter de timeline (sem FK rígido, sem meta)

**Status:** accepted
**Date:** 2026-06-04
**Tags:** schema, biomarkers, timeline, diabetes, glicemia, healthsync, samd
**Spec:** 012-diabetes-t2-support (Fase C)
**Relaciona:** ADR-050 (FP-3 timeline event-agnóstica), R-252 (adapter), R-021, ADR-062 (SaMD)

## Context

Rastrear só a dose conta metade da história do diabético; paciente e médico cruzam **dose × efeito
(glicemia)**. O modelo deve nascer genérico (glicemia, peso, PA, batimentos) p/ crescer sem migration
e abrir porta a import futuro (HealthKit/Google Fit/Health Connect). A timeline (R-252) já é
event-agnóstica com adapter — comentário no código prevê "biomarkers_log → adapter biomarker".

## Decision

1. **Tabela `biomarkers_log`** genérica: `id, user_id, type (default 'glicemia'), value numeric,
   unit text, measured_at timestamptz, context text, source text (default 'manual'), notes, created_at`.
   Grants + RLS (`user_id=auth.uid()`) + REVOKE anon (template CLAUDE.md). Enums PT (R-021).
2. **`type`/`source` extensíveis sem migration:** `type ∈ {glicemia, peso, pressao_arterial,
   batimentos, ...}`; `source ∈ {manual (v1), healthkit, google_fit, health_connect, cgm_* (futuro)}`.
3. **Entra na timeline via adapter** `biomarkersToEvents` → `TimelineEvent[]` `type='biomarker'`
   (R-252) — **sem tocar** o builder puro (`timeline.js`) nem a UI de dose. Card via `eventCardRegistry`.
4. **Sem FK rígido** com `dose_instances` — correlação só **temporal** (instante absoluto). Glicemia
   é evento independente.
5. **Sem meta/alvo** armazenado como parâmetro — só log (linha SaMD, ADR-062). `context` é **manual**.

## Consequences
- **+** Um modelo serve todos os biomarcadores; HealthSync sem migration (`source`).
- **+** Timeline híbrida sem refactor (FP-3 já preparado).
- **−** `context` texto livre/enum frouxo pode gerar drift — definir enum PT no schema (R-021/R-082).
- Migração: tabela nova vazia; nenhum dado legado.

## Alternatives
- Tabela só `glucose_log` (rejeitado: não cresce p/ peso/PA sem migration).
- FK rígido glicemia↔dose (rejeitado: glicemia é independente; acopla sem ganho).
- Armazenar meta glicêmica (rejeitado: aproxima Classe II SaMD — ADR-062).
