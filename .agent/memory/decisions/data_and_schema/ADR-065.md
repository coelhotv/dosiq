# ADR-065 — `units_per_ml` default NULL + fallback unit-aware (substitui o blanket 20)

**Status:** proposed
**Data:** 2026-06-12
**Contexto:** 012 Fase B3 (débito FR-013b exposto no smoke da B2)
**Relaciona:** ADR-058 (define `units_per_ml`), AP-225, R-104, R-270, R-271

## Contexto

`medicines.units_per_ml` nasceu (ADR-058) com **DEFAULT 20** (gotas/ml). 20 é a densidade de
gotas, mas é **carimbado em TODO líquido** — inclusive insulina (UI ≈ 100/ml) → conversão UI→ml
fica **5× errada** quando a densidade não é informada. O problema não é "20 vs NULL", é o default
ser **único (blanket)** para unidades de tomada com densidades físicas diferentes. mg já saiu dessa
conta na B2 (usa `dosage_per_pill`).

## Decisão

1. **Coluna `units_per_ml` default `NULL`** (`ALTER COLUMN ... DROP DEFAULT`). Novas linhas não
   nascem com 20.
2. **Fallback unit-aware** (não blanket) na conversão razão→ml, aplicado **pela unidade de tomada**
   (`protocols.intake_unit`):
   - `gotas → 20` (conta-gotas universal, baixo risco clínico)
   - `UI → 100` (padrão U-100; insulina)
   - `mg → dosage_per_pill` (concentração mg/ml do cadastro — já na B2)
   - sem valor **e** sem padrão seguro p/ a unidade → **`RAISE EXCEPTION`** / erro explícito
     (Const. IX — não chuta dose). Remove o `COALESCE(..., 20)` blanket do ramo gotas/UI da RPC.
3. **Backfill derivado do tratamento**: por medicine, inspecionar `protocols.intake_unit` associado
   e gravar a densidade real (UI→100, gotas→20, mg/sem-tratamento/não-líquido→NULL). Backfill e
   runtime concordam. Tie-break multi-tratamento: priorizar a unidade que exige densidade (UI>gotas);
   logar o caso raro.

## Consequências

- (+) Insulina sem densidade explícita não converte mais com 20; erro honesto em vez de dose errada.
- (+) Um só mecanismo (unidade→densidade) em RPC, `doseToMl`, `formatIntakeDose`.
- (−) Mutação em prod (DROP DEFAULT + UPDATE de backfill) — requer autorização do PO e diff do
  `pg_get_functiondef` ao vivo (AP-217), assinatura intacta (AP-221).
- Risco: linhas legadas com 20 legítimo (gotas) vs carimbado — o backfill por tratamento resolve a
  maioria; medicines órfãos viram NULL e a densidade é capturada no próximo tratamento (FR-025).
