# ADR-062 — Fronteira SaMD: registro passivo, zero cálculo/sugestão de dose

**Status:** accepted
**Date:** 2026-06-04
**Tags:** samd, regulatory, anvisa, diabetes, safety, constitution
**Spec:** 012-diabetes-t2-support (todo o épico)
**Relaciona:** Constitution I (Health Data Safety), ADR-060

## Context

ANVISA RDC 657/2022 + RDC 751/2022 (Regra 11, transpõe IMDRF) classificam software por risco
clínico. **Registrar/exibir** glicemia + dose + relatório = logbook/monitoramento passivo → fora ou
Classe I. **Sugerir/calcular dose** de insulina/bolus (a partir de glicemia/carbo) = suporte a
decisão terapêutica → **Classe II** (registro ANVISA + clearance). Bolus calculators (InPen, BlueStar,
T1D1) são Classe II FDA confirmados.

## Decision

O épico de diabetes (e o Dosiq em geral) é **registro passivo + relatório**:
- ✅ Registrar glicemia (`biomarkers_log`), insulina/GLP-1 aplicada (editável no check), timeline
  correlacionada, export PDF descritivo.
- ❌ **NUNCA** calcular nem sugerir dose de insulina/bolus.
- ❌ **NÃO** armazenar meta glicêmica nem fator de sensibilidade como **parâmetro de cálculo**.
- ⚠️ Carboidrato (se um dia logado) = **dado bruto**, jamais insumo de fórmula de bolus.
- Disclaimers explícitos; acurácia de entrada manual é responsabilidade do usuário.

## Consequences
- **+** Mantém o Dosiq Classe I / fora de registro ANVISA — sem barreira regulatória.
- **+** Alivia carga cognitiva por **registro rápido + memória de última dose** (não por cálculo).
- **−** Não entrega calculadora de bolus (valor clínico real p/ T1) — consciente; seria outro produto regulado.
- Governa todas as fases: qualquer feature que derive dose de biomarcador é **bloqueada** por esta ADR.

## Alternatives
- Calculadora de bolus opt-in (rejeitado: vira dispositivo médico regulado; fora do escopo/risco).
- Exibir meta glicêmica de referência (zona cinza — adiado; só se for display puro, nunca cálculo).
