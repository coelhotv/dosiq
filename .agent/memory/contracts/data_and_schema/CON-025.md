# CON-025 — Biomarcadores (biomarkers_log + schema + repo + adapter)

**Domínio:** data_and_schema
**Origem:** 012 Fase C (PR 3a) · ADR-060
**Relaciona:** R-252 (adapter timeline), R-274 (Base+superRefine), R-082/R-271 (CHECK↔Zod), ADR-062 (SaMD)

## Tabela `public.biomarkers_log`

`id uuid pk` · `user_id uuid → auth.users` · `type text NOT NULL default 'glicemia'` ·
`value numeric NOT NULL` · `value_secondary numeric NULL` (2º componente — PA diastólica) ·
`unit text NOT NULL` · `measured_at timestamptz NOT NULL default now()` ·
`context text NULL CHECK (NULL OU jejum/pre_refeicao/pos_refeicao/ao_deitar/outro)` ·
`source text NOT NULL default 'manual'` · `notes text` · `created_at timestamptz default now()`.
RLS `user_id=auth.uid()` (SELECT/INSERT/UPDATE/DELETE), REVOKE anon. Índice `(user_id, measured_at DESC)`.

**type/source SEM CHECK** (extensíveis sem migração — ADR-060); enum v1 só no Zod. **context COM CHECK**
(enum fechado — R-082/R-271). Sem FK rígido com dose_instances (correlação temporal). Sem meta (SaMD).

## `biomarkerLogSchema` (`packages/core/src/schemas/`)

Enums: `BIOMARKER_TYPES` (glicemia/peso/pressao_arterial/batimentos), `BIOMARKER_CONTEXTS`,
`BIOMARKER_SOURCES`, `BIOMARKER_TYPE_UNITS` (glicemia=mg/dL, peso=kg, PA=mmHg, batimentos=bpm).
`value`/`value_secondary` via `preprocess('' → null)` + coerce positive (vírgula PT-BR no caller).
**superRefine:** `type='pressao_arterial'` ⇒ `value_secondary` obrigatório; demais ⇒ deve ser NULL.
Update = `biomarkerObject.partial()` SEM refine (R-274). `validateBiomarkerLog`/`validateBiomarkerLogUpdate`.

## `createBiomarkerRepository({client, getUserId})` (`packages/core/src/repositories/`)

`list({type,fromTs,toTs,limit})` · `getLatest(type?)` (card "Última medida") · `create(b)` ·
`update(id, patch)` · `remove(id)`. RLS garante posse (eq user_id em update/delete). create omite
`measured_at` ausente → DB default (sem `new Date` no core — R-020).

## Adapter `biomarkersToEvents(rows) → TimelineEvent[]` (`services/timelineService.js`)

Puro; `type='biomarker'`, `occurred_at=measured_at`, payload {biomarkerType,value,valueSecondary,unit,context}.
Descarta linha sem measured_at. NÃO toca o builder `timeline.js` (R-252). `TIMELINE_EVENT_TYPES.BIOMARKER`.

## Nota de consumo (As-Built 3a)

Adapter + `eventCardRegistry` são **web-only** (apps/web). **Mobile não tem registry de timeline**:
o "Hoje" usa `splitDayTimeline` (CON-024 doseZones, dose-only); biomarcador entra como card
**"Última medida" no FIM** via `_useTodayDerived`/TodayScreen, e a Área de Medidas (`@measures`) é
tela própria. PR 3b (web) consome o adapter no `HistoryDayPanel`/`eventCardRegistry`.
