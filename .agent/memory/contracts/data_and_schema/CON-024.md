# [CON-024] Dose zones API (classificação temporal + DoseItems de dose_instances)

**Status:** active · **Layer:** warm · **Domain:** data_and_schema
**Criado:** 2026-05-31 (PR-F4.3a / Fase 4)

## Interface

`packages/core/src/utils/doseZones.js` (PURO — sem I/O, sem APIs de browser):

- `classifyDose(scheduledFor, now, lateWindowMinutes=120, nowWindowMinutes=60, upcomingWindowMinutes=240, isRegistered=false, toleranceMinutes=null)`
  → `'done'|'late'|'now'|'upcoming'|'later'|null`.
  Classifica uma ocorrência pelo seu instante ABSOLUTO (`scheduled_for` timestamptz ou Date)
  vs `now`. `isRegistered` → `'done'`. Cutoff de atraso = `toleranceMinutes ?? lateWindowMinutes`
  (NÃO 120 fixo): após `scheduled_for + tolerância` → `null` (missed, fora do actionável,
  espelha `markMissedDueInstances`). `scheduledFor` inválido → `null`.

- `buildDoseItemsFromInstances(instances, protocols, tz='America/Sao_Paulo')` → `DoseItem[]`.
  Junta cada `dose_instance` com seu protocolo (medicine/treatment_plan em contexto).
  Pula `skipped_paused`/`skipped_user` (não são pendência) e instâncias sem protocolo.
  `DoseItem` carrega `instanceId` (âncora direta p/ registro), `scheduledFor` (ISO absoluto),
  `scheduledTime` ("HH:MM" local derivado no `tz`), `status`, `toleranceMinutes`, `isRegistered`,
  `registeredAt`, metadata de medicamento + `planBadge`.

- `DEFAULT_TZ = 'America/Sao_Paulo'`.

Reexportadas por `@dosiq/core` (barrel `packages/core/src/utils/index.js`).

## Invariantes
- Funções PURAS: classificação por instante absoluto (AP-194) — nunca `setHours()` no dia local;
  elimina slot fantasma cross-meia-noite.
- `tz` injetável governa apenas a derivação de `scheduledTime` (HH:MM local), nunca o cutoff.
- `scheduled_for` é ISO 8601 → ordenável lexicograficamente sem parse.
- Fonte única `dose_instances` (ADR-054, R-248) — sem inferência ±2h sobre logs.

## Consumidores
- Web: `apps/web/src/features/dashboard/hooks/useDoseZones.js` (re-exporta + hook),

- Mobile: `_useTodayDerived.js` (F4.3b — migração da timeline do Hoje).
