# CON-026 — `createDoseLogService` factory interface no core

## Assinatura da Factory

```javascript
import { createDoseLogService } from '@dosiq/core'

const doseLogService = createDoseLogService({
  client,      // Cliente Supabase
  getUserId,   // Função async () => string (resolve user_id)
})
```

## Métodos do Serviço

### 1. `registerDose(logData, options = {})`

Registra uma tomada de dose (atômica com relação ao estoque FIFO).

- **Parâmetros**:
  - `logData`: `{ medicine_id: string, protocol_id: string|null, taken_at: string, quantity_taken: number, notes?: string|null }`
  - `options`: `{ instanceId?: string|null }` (ID da ocorrência materializada a ancorar)
- **Retorno**: `Promise<MedicineLog>` (com `dose_instance_id` atualizado se ancorado)
- **Validação**: Valida `logData` usando o `logSchema` canônico.
- **Rollback**: Se `consume_stock_fifo` RPC falhar (ex: sem estoque), deleta o log inserido.

### 2. `undoDose(instanceId)`

Desfaz o registro de uma dose ancorada a uma ocorrência.

- **Parâmetros**:
  - `instanceId`: `string` (UUID da dose_instance)
- **Retorno**: `Promise<{ success: boolean }>`
- **Comportamento**:
  - Busca a ocorrência no banco para obter `medicine_log_id`.
  - Se houver log, chama `restore_stock_for_log` RPC e deleta o log de `medicine_logs`.
  - Reverte o status da `dose_instance` de `taken` para `pending` ou `missed` de acordo com a tolerância em relação à data agendada.

### 3. `updateOrphanLog(logId, updates)`

Atualiza um log avulso (PRN/orphan) reajustando o estoque.

- **Parâmetros**:
  - `logId`: `string`
  - `updates`: `{ taken_at?: string, quantity_taken?: number, medicine_id?: string, notes?: string|null }`
- **Retorno**: `Promise<{ success: boolean }>`
- **Comportamento**:
  - Se a quantidade ou medicamento mudarem: chama `restore_stock_for_log` para estornar o consumo anterior, salva a atualização, e chama `consume_stock_fifo` para consumir o novo.
  - Em caso de falha de reconsumo, restaura o estado anterior e reconsome o estoque antigo.

### 4. `deleteOrphanLog(logId)`

Exclui um log avulso devolvendo o estoque ao inventário.

- **Parâmetros**:
  - `logId`: `string`
- **Retorno**: `Promise<{ success: boolean }>`
- **Comportamento**:
  - Devolve estoque chamando `restore_stock_for_log`.
  - Exclui o log em `medicine_logs`.
  - Se houver `dose_instance_id` no log (defensivo), reverte o status da instância para `pending` ou `missed`.
