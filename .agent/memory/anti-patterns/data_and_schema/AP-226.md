# AP-226 — float artifact vaza por formatNumberPtBR

## Sintoma

Chip/card de concentração exibe `0,36000000000000004 mg / 0,3ml` em vez de
`0,36 mg / 0,3ml`. O mesmo valor sujo é persistido em `dosage_per_pill`.

## Causa

`formatNumberPtBR` (e qualquer `String(Number(x))`) **não arredonda** — exibe o
float cru. Multiplicar/dividir concentração sem limpar:

```js
// ERRADO
const amount = ratio * vol            // 1.2 * 0.3 → 0.36000000000000004
return formatNumberPtBR(amount)       // "0,36000000000000004"

dosage_per_pill: amount / denom       // dízima persistida no banco
```

`Number.isFinite` é `true` pra dízima → passa por toda validação. Detectado só por
inspeção visual / review (Gemini #661).

## Correção

`cleanFloat(x)` antes de exibir E de persistir ([[R-277]]):

```js
// CERTO
const amount = cleanFloat(ratio * vol)   // 0.36
dosage_per_pill: cleanFloat(amount / denom)
```

## Cuidado correlato

`Number('') === 0` (não `NaN`) — campo numérico vazio (permitido p/ suplemento)
convertido sem guard salva `0` em vez de `null`. Verificar valor preenchido
(`raw !== '' && != null`) antes de converter. Mesmo PR #661 (HIGH).
