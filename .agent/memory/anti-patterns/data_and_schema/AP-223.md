# AP-223 — Zod v4: `.partial()` incompatível com `.superRefine()`

## Problema

Em Zod v4, chamar `.partial()` em um schema que possui `.superRefine()` lança erro em runtime:

```
Error: .partial() cannot be used on object schemas containing refinements
```

Não há erro em build, lint, ou testes unitários que não cubram o caminho de update.
Só explode em produção quando `validateNudgeUpdate` (ou equivalente) é chamado.

```js
// ❌ BUG: superRefine + partial() = crash em runtime
const nudgeSchema = z.object({ ... }).superRefine((data, ctx) => { ... })

export function validateNudgeUpdate(data) {
  const partialSchema = nudgeSchema.partial() // 💥 lança aqui
  ...
}
```

## Fix — separar base schema do refinement

```js
// ✅ CORRETO: base sem refinements → .partial() funciona
const nudgeBaseSchema = z.object({ ... })

// schema completo com cross-field validation → usado só no create
const nudgeSchema = nudgeBaseSchema.superRefine((data, ctx) => { ... })

export function validateNudgeCreate(data) {
  return nudgeSchema.safeParse(data) // usa superRefine
}

export function validateNudgeUpdate(data) {
  const partialSchema = nudgeBaseSchema.partial() // sem superRefine → OK
  return partialSchema.safeParse(data)
}
```

## Por que o update não precisa do superRefine

Update é PATCH semântico — campos ausentes são ignorados. Cross-field validation
(ex: `action_type === 'navigate'` exige `action_payload.screen`) só faz sentido
quando ambos os campos estão presentes no payload. O frontend valida isso antes
de submeter; o backend valida o shape de cada campo individualmente via `.partial()`.

## Quando aplicar

Sempre que um schema Zod tiver `.superRefine()` e precisar de variante `.partial()`:
1. Extrair `BaseSchema = z.object({...})`
2. `Schema = BaseSchema.superRefine(...)`
3. Update usa `BaseSchema.partial()`, create usa `Schema`

**Why:** `.partial()` em Zod v4 não aceita schemas com refinements — lança `Error` em runtime
(028 admin nudges — salvar edição de nudge crashava o handler serverless).

**How to apply:** Ao adicionar `superRefine` a qualquer schema que também expõe `validateXxxUpdate`,
separar base + refined imediatamente. Relaciona [[AP-222]] (bugs silenciosos em admin nudges).
