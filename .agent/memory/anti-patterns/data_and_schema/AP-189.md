# [AP-189] Fallback de Arrays Vazios `[]` do Banco usando Operador `||`

## Pattern
Utilizar o operador lógico OR (`||`) para obter um valor padrão quando um campo de array (ex: `weekdays` ou `tags`) pode ser retornado como vazio pelo banco de dados (Supabase/PostgreSQL).

Exemplo comum:
```javascript
const activeDays = protocol.weekdays || protocol.days;
```

---

## Impacto

Este anti-padrão gera **falhas lógicas silenciosas graves** e comportamentos inesperados na aplicação (2 ocorrências reais auditadas na base, ex: PR #592):

1. **Truthy Fallacy em JavaScript:** Em JS, arrays vazios (`[]`) são objetos, e **todos os objetos em JavaScript são avaliados como truthy** (inclusive novos arrays).
2. **Anulação do Fallback:** A expressão `protocol.weekdays || protocol.days` detectará `[]` (que é truthy) e avaliará imediatamente para `[]`, anulando por completo o fallback para `protocol.days`.
3. **Falhas no Cálculo de Adesão:** Em tratamentos com frequências do tipo "dias específicos" que não foram preenchidos (gerando array vazio `[]` no banco), a lógica assumirá o array vazio em vez de cair na propriedade de frequência em dias (ex: `protocol.days` = 1), fazendo com que o sistema calcule `0` doses esperadas para o dia e infle ou zere artificialmente o score de adesão do paciente.

---

## Detecção

Grep por expressões que fazem curto-circuito lógico com propriedades do tipo array retornadas de consultas no Supabase ou APIs:
* Procurar por `||` acoplados a propriedades como `weekdays`, `tags`, `logs`, `medicines`, `entries` etc.

---

## Como Corrigir

Sempre realize a validação do tamanho real do array (`length > 0`) antes de aplicar o fallback lógico, ou utilize encadeamento opcional e operadores ternários robustos:

### ❌ Incorreto
```javascript
// Se weekdays for [], activeDays será [] (truthy) e days nunca será usado
const activeDays = protocol.weekdays || protocol.days;
```

### ✅ Correto (Validação por Tamanho)
```javascript
const activeDays = (protocol.weekdays && protocol.weekdays.length > 0) 
  ? protocol.weekdays 
  : protocol.days;
```

### ✅ Correto (Optional Chaining & Nullish Coalescing)
```javascript
// Se weekdays for nulo/indefinido, cai no fallback. Se for [], checa tamanho.
const activeDays = protocol.weekdays?.length ? protocol.weekdays : protocol.days;
```

---

## Incidentes de Exemplo
* **PR #592 (Wave 12 - Cálculo de Calendários):** A refatoração do cálculo de dias ativos para medicamentos da lista de Dona Maria introduziu o padrão `protocol.weekdays || protocol.days` quando o banco passou a retornar `[]` por padrão para weekdays de protocolos diários, resultando no desaparecimento de medicamentos da timeline diária de adesão. Corrigido com a checagem explícita de `length`.
