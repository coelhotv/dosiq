## Problema

`@supabase/supabase-js` ≥ 2.90 bundla `@supabase/realtime-js` que verifica a existência de `WebSocket` global **no construtor** de `SupabaseClient` — mesmo sem nenhuma chamada Realtime. Node < 22 não tem `WebSocket` nativo. Resultado: crash no **import do módulo**, não numa chamada. Qualquer função serverless que importe o cliente cai imediatamente antes de executar qualquer handler.

## Por que não é óbvio

- Erro ocorre em import, não em uso → nenhum teste unitário pega (JSDOM/browser env tem WebSocket global)
- `ws` pode ser dep transitiva resolvida localmente (funciona em dev/Node 22+) mas não em prod (Node 20 Vercel)
- O crash afeta 100% das funções que importam o cliente, não apenas as que usam Realtime

## Fix

```js
import ws from 'ws';   // dep direta no package.json
export const supabase = createClient(url, key, {
  realtime: { transport: ws },
});
```

**Why:** `realtime: { transport: ws }` satisfaz o check do construtor sem exigir WebSocket nativo.

## How to apply

Sempre que criar ou atualizar `server/services/supabase.js` (ou equivalente), confirmar `ws` como dep direta e `realtime: { transport: ws }` no createClient. Ver [[AP-211]] (dep transitiva sem lock direto).
