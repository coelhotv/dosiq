## Problema

`validate:agent` e `test:critical` rodam em ambiente Vitest/JSDOM com globals de browser (`WebSocket`, `fetch`, etc.). Erros que ocorrem no **construtor** ou no **import** de módulos serverless só são visíveis quando a função é invocada em Node puro — exatamente o ambiente Vercel. Resultado: regressões de bootstrap chegam 100% a prod.

## Por que não é óbvio

- Test suite verde ≠ função serverless inicializa corretamente
- O erro de import é silencioso no CI (outro workspace, outro env)
- Não há gate automático entre "build passou" e "função inicia em Node 20 puro"

## Fix

Adicionar smoke test de import isolado em Node puro para módulos serverless críticos:

```bash
# scripts/smoke-server.mjs
import '/Users/.../server/services/supabase.js';
import '/Users/.../server/bot/botFactory.js';
console.log('Server modules OK');
```

```bash
node --input-type=module < scripts/smoke-server.mjs
```

Rodar esse script no CI (GitHub Actions / pre-deploy hook) em Node 20 (mesma versão da Vercel).

## How to apply

Todo módulo importado por funções `api/*.js` ou `server/` deve ter cobertura no smoke test de import. Adicionar ao CI antes de deploy prod. Ver [[R-262]] (regra derivada) e [[AP-210]] (incidente de origem).
