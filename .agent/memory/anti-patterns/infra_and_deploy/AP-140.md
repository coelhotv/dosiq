# AP-140 — Duplicate Imports in ESM Node.js

## O que é?
Ter dois ou mais statements `import { ... } from './file.js'` apontando para o mesmo destino no topo de um arquivo.

## Por que é um problema?
1. **Falha no CI**: Regras estritas de lint (como `import-x/no-duplicates`) barram o build.
2. **Manutenibilidade**: Se o caminho do arquivo mudar, você precisa atualizar em múltiplos lugares.
3. **Legibilidade**: Espalha as dependências do arquivo, dificultando entender de onde vem cada símbolo.

## Como evitar?
Agrupe todos os símbolos importados de um mesmo arquivo em um único bloco.

**ERRADO:**
```javascript
import { schemaA } from './schemas.js';
import { helper } from './utils.js';
import { schemaB } from './schemas.js'; // DUPLICADO
```

**CERTO:**
```javascript
import { schemaA, schemaB } from './schemas.js';
import { helper } from './utils.js';
```
