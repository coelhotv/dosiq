# AP-263 — tsx/vitest mascaram import extensionless: smoke local verde, runtime Vercel quebrado

**Domínio**: infra_and_deploy · **Descoberto**: 2026-07-04 (040 gate F3, 2ª ocorrência da classe R-282) · **Severidade**: alta

## Sintoma

Sessões 3.2/3.3 migraram `server/notifications` pra TS deixando 20 imports relativos extensionless em 7 arquivos. TODOS os gates locais passaram: tsc (moduleResolution bundler não valida extensão), vitest (Vite resolve), e o smoke Node ESM do playbook — que rodava via **tsx** (runtime do server desde F3.3), e tsx resolve extensionless.

## Consequência

Preview Vercel: 4 rotas (`notify`, `dlq`, `admin/nudges`, `feedbacks`) com `FUNCTION_INVOCATION_FAILED` / `ERR_MODULE_NOT_FOUND` — `api/` importa o dispatcher e roda Node ESM puro. Nenhuma ferramenta local pegava a classe; só o preview.

## Regra de prevenção

1. Guard mecânico no `scripts/strict-island.sh`: grep bloqueante de import relativo sem `.js` em fonte de `api/`+`server/` (roda em toda sessão) — cobre o que tsc bundler, vitest e tsx não validam.
2. Smoke via tsx serve pra validar grafo/env de cold start, mas NÃO valida extensão — não confundir os dois sinais.
3. Preview Vercel continua obrigatório no gate da fase (única validação fiel do runtime).
