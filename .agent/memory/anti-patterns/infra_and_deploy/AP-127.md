# [AP-127] Cross-Boundary Import Leak

## Problema
Arquivos de um domínio (ex: `apps/web`) importando arquivos de outro domínio (ex: `server/`) usando caminhos relativos profundos (ex: `../../../../../server/utils`).

## Sintomas
- Quebra de testes quando arquivos são movidos.
- Dependência circular entre camadas que deveriam ser isoladas.
- Erros de compilação no CI pois o `node_modules` de um domínio não contém as dependências do outro.

## Solução
- Utilizar a regra `no-restricted-imports` para bloquear acessos a diretórios fora do domínio.
- Centralizar código compartilhado em `src/shared` ou pacotes em `packages/*`.
