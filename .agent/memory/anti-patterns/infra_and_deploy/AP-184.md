# AP-184 — Import ESM de subpath sem extensão: Vite/vitest mascaram, Node ESM estrito (Vercel) quebra

**Categoria:** infra_and_deploy
**Severidade:** High (prod-down)
**Detectado:** 2026-05-29 (runtime Vercel, primeiro invoke de `api/generate-doses.js`)
**Status:** corrigido

## Sintoma

```
Error [ERR_MODULE_NOT_FOUND]: Cannot find module
'/var/task/node_modules/zod/v4/locales/pt' imported from
/var/task/packages/core/src/zodSetup.js
```

Endpoint serverless que importa o barrel `@dosiq/core` falha no boot. Todos os gates locais passam (lint, `validate:agent` 932/932, build web) — o erro só aparece no runtime Vercel.

## Causa raiz

`zodSetup.js` fazia `import pt from 'zod/v4/locales/pt'` (sem extensão). O exports map do zod 4.4.3:

```json
"./v4/locales/*": { "import": "./v4/locales/*" }
```

O glob `*` passa o remainder **literal, sem anexar extensão**. `zod/v4/locales/pt` → resolve para o arquivo `pt` (não existe; o arquivo é `pt.js`).

- **Vite / vitest:** resolver leniente anexa `.js` automaticamente → resolve. Mascara o bug em 100% dos gates locais e no app web (bundled).
- **Node ESM estrito (runtime serverless Vercel, onde `packages/core` é deployado como ESM raw, não bundled):** não anexa extensão → `ERR_MODULE_NOT_FOUND`.

`api/notify.js` não quebrava porque seu grafo de import não alcança `zodSetup`. O bug ficou latente até o primeiro endpoint serverless (`generate-doses`) puxar o barrel do core.

## Correção

Extensão explícita:

```javascript
import pt from 'zod/v4/locales/pt.js'
```

O glob `*` captura `pt.js` → `./v4/locales/pt.js` (existe). Resolve nos dois resolvers (Vite/vitest E Node ESM estrito).

## Regra geral

Em código que será deployado como **ESM raw no serverless** (`packages/*` e `server/*` importados por `api/*`), sempre usar **extensão explícita `.js`** em imports de subpath de pacote — Vite e vitest não detectam a falta porque anexam extensão automaticamente. Os gates locais NÃO pegam esta classe; só o runtime Node estrito pega.

Detecção: `grep -rnE "from ['\"][a-z@].*/[^.']+['\"]" packages/core/src server/` e auditar subpaths de pacote sem extensão que entrem no grafo de import de `api/`.
