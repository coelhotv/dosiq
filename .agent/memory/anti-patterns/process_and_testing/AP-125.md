# [AP-125] Stale Dispatcher Mock Contracts

**Status:** active · **Layer:** warm · **Domain:** process_and_testing
**Reconciliado:** 2026-05-31 (D5 — detail file recriado a partir do índice; arquivo original ausente/perdido)

## Sintoma
Mocks de teste que esperam estruturas de payload prontas (L2) quando a arquitetura foi
refatorada para enviar dados brutos de domínio (L1) → testes passam verdes mas validam um
contrato que não existe mais (falso positivo).

## Regra
Ao refatorar a fronteira entre camadas (L1 dados brutos → L2 apresentação), atualizar os
mocks de teso para o novo contrato. Mock desatualizado mascara regressão real.
