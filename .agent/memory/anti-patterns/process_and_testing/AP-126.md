# [AP-126] Config Linting Regression

## Problema
Tentar rodar regras estritas de ESM ou guardrails de IA em arquivos de configuração (`*.config.js`, `vite.config.js`, `babel.config.js`).

## Sintomas
Erro `[ERR_PACKAGE_PATH_NOT_EXPORTED]` ao tentar importar módulos internos de ferramentas (ex: `vite/internal`). Isso ocorre porque o ESLint tenta validar caminhos que não são exportados publicamente pelos pacotes.

## Solução
Sempre adicionar `**/*.config.js` e arquivos de configuração específicos ao array de `ignores` do bloco de linting principal.
