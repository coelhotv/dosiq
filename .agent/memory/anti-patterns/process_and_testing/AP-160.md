# [AP-160] Opus violando R-010 (ordem de hooks) em fixes incrementais pós-validação

## Sintoma
Cavecrew (Sonnet/Haiku) entrega componente original respeitando R-010 (States → Memos → Effects → Handlers). Opus (arquiteto), durante fixes incrementais pós-validação PO, adiciona hooks novos no LUGAR ERRADO da estrutura:
- Adiciona `useFocusEffect` no início do componente, antes dos `useMemo` que ele depende
- Adiciona `useState(sheetOpen)` depois de um `useMemo(initialValues)`
- Detectado por Gemini-Code-Assist em revisão de PR (commits incrementais ≠ código zero-shot)

## Histórico Fase 1
- M1.7 (DetailScreen) — Sonnet entregou clean. Opus adicionou `useFocusEffect` antes dos memos em fix subsequente. Detectado no PR #556.
- M1.2 (FormScreen) — Opus escreveu do zero. `useState(sheetOpen)` antes de `useMemo(initialValues)` (correto por sorte) MAS depois adicionou hooks dependentes (`useFormState`, `useMedicineMutation`) misturados entre memos. Detectado no PR #556.
- Ambos fix em commit 412cdaf8 (M1.2).

## Solução de processo
Quando adicionar hooks em componente existente:
1. **Antes de editar**, ler o componente completo
2. Identificar os 4 blocos (States, Memos, Effects, Handlers) — comentário explícito recomendado:
   ```javascript
   // States (R-010 — States → Memos → Effects → Handlers)
   const [x, setX] = useState(...)

   // Memos
   const y = useMemo(...)

   // Hooks dependentes (consomem memos acima)
   const z = useCustomHook(y)

   // Effects
   useFocusEffect(...)

   // Handlers
   const handle = useCallback(...)
   ```
3. Adicionar o hook novo ao bloco correto, NÃO no fim do arquivo "para ficar perto do que ele afeta"
4. Rodar `rtk lint <file>` antes de commitar — lint pega `react-hooks/rules-of-hooks` mas NÃO pega ordem semântica de R-010

## Por que cavecrew Sonnet/Haiku acertam mais
- Brief (R-230) inclui R-010 explícito → Sonnet zero-shot 0 erros
- Opus arquiteto faz fixes "rápidos" pulando o ritual do brief → comete em commits incrementais

## Aplicação
- Adicionar lint custom rule `react-hooks/hook-order-by-category` se possível (investigação futura)
- Code review template: "verificou R-010 nos novos hooks?"
