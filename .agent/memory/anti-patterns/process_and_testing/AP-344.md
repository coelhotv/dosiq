# AP-344 — Schema com `additionalProperties` puro devolve `{}` e o engine reporta SUCCESS

**Detectado:** spec 060, T035b (piloto do `agy`), 2026-09-01
**Relaciona:** [[AP-325]] · [[R-275]]

## O sintoma

Dois chunks de 35 regras enviados ao `agy` com `--output-format json --json-schema`. Ambos voltaram
com `"status": "SUCCESS"`, `usage.output_tokens` na casa dos 50–69 mil — e `structured_output` igual
a `{}`. Nenhum erro, nenhum stderr útil, quota gasta.

O schema era este:

```json
{ "type": "object",
  "additionalProperties": { "type": "array", "items": { "type": "string" } } }
```

Ou seja: objeto de chaves arbitrárias (`{"AP-186": ["glob", ...]}`). Legal em JSON Schema, **inútil
como contrato de saída estruturada**: o motor não tem nome de campo para preencher e devolve o
objeto vazio, que satisfaz o schema.

## A correção

Nomear os campos. Um array de objetos resolve e aceita chaves dinâmicas como *dado*:

```json
{ "type": "object", "required": ["results"],
  "properties": { "results": { "type": "array", "items": {
      "type": "object", "required": ["id","paths"],
      "properties": { "id": {"type":"string"},
                      "paths": {"type":"array","items":{"type":"string"}} } } } } }
```

Funcionou na primeira tentativa, com 4.751 tokens de raciocínio contra os 52 mil do chunk que se
perdeu.

## Por que é a mesma doença do [[AP-325]]

`status: SUCCESS` é **asserção do envelope**, não prova de que houve resposta. O `ai-review.sh` já
documenta a classe ("engine responde em prosa, sai 0, o merge devolve None e o chunk ainda conta na
cobertura") e resolve exigindo schema — mas exigir schema **não basta**: um schema mal-formado
reproduz a falha por dentro do próprio mecanismo que existe para evitá-la.

## O gate

Nunca aceitar `status` como evidência. Contar os itens:

```bash
python3 -c "import json,sys; d=json.load(open(sys.argv[1]));
print(len((d.get('structured_output') or {}).get('results', [])))" out.json
```

Zero item com status SUCCESS é **falha**, e falha cara: a chamada foi paga. Vale para qualquer engine
com saída estruturada, não só o `agy`.

## Sintoma secundário que aparece junto

Chunk grande (35 regras) estourou o orçamento de raciocínio — 69.178 tokens de saída, 65.641 deles de
thinking, resposta perdida inteira. Com 18 regras por chunk o mesmo prompt fecha. Saída vazia tem
**duas** causas possíveis; conferir o schema antes de culpar o tamanho.
