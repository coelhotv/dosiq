# [AP-057] Closure Reference Leak (Snapshot ReferenceError)

## Contexto
Ocorre ao tentar criar um objeto de snapshot ou log dentro de um bloco `try/catch` ou callback assíncrono, referenciando uma variável (`today`) que foi tratada como global ou definida em um escopo não capturado.

## Problema
App crasha com `ReferenceError: today is not defined` no momento da criação do snapshot, mesmo que o fetch inicial tenha tido sucesso.

## Como evitar
Sempre defina variáveis de contexto (como a data local) no início da função `load` ou dentro do escopo imediato onde o snapshot é gerado.
