# [AP-198] "Cannot read property 'useState' of null" — Metro empacota múltiplas versões de React

**Status:** active · **Layer:** warm · **Domain:** react_and_ui
**Reconciliado:** 2026-05-31 (D5 — renumerado de uma colisão de ID com AP-H22; arquivo criado a partir do índice)

## Sintoma
Crash `TypeError: Cannot read property 'useState' of null` no app nativo, causado pelo Metro
empacotando múltiplas versões de React (duplicação de instância) → hooks resolvem `null`.

## Regra
Forçar instância única de React/React-DOM no Metro (ver R-160/R-174): versões idênticas e
exatas (sem ranges) entre os workspaces; configurar `metro.config.js` para resolver um único
React. Nunca permitir 2 cópias de React na árvore de módulos.
