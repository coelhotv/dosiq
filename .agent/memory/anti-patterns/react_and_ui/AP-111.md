# AP-111: Blind Toggle Fallacy

Alternar um estado booleano usando negação direta (`!prev`) quando o estado inicial é `undefined` mas o comportamento visual padrão é "verdadeiro".

## O Sintoma
O usuário precisa clicar duas vezes em um botão ou acordeão para ele responder na primeira vez que a tela é carregada.

## A Solução
Implementar a Regra **R-186**: Normalizar o estado atual (`prev !== false`) antes de aplicar a inversão.
