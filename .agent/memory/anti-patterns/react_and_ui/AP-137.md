# [AP-137] React Compiler vs Manual Memoization

**Symptom:** `Compilation Skipped: Existing memoization could not be preserved` lint error.
**Domain:** `apps/web` (React 19)

## Problem
A mismatch between manual dependency arrays in `useMemo`/`useCallback` and the dependencies inferred by the React Compiler.

## Why it's bad
- The React Compiler (React Forget) attempts to optimize components by auto-memoizing.
- If it detects a manual `useMemo` where the dependencies are "less specific" than what it inferred (e.g., passing `dashboardData` when only `dashboardData.protocols` is used), it will bail out of optimization for that component to prevent bugs.

## Fix
Ensure the manual dependency array exactly matches the property-level access used inside the hook.

### ❌ Bad
```javascript
const data = useMemo(() => {
  return process(dashboardData.protocols);
}, [dashboardData]); // Trigger: Inferred less specific property than source
```

### ✅ Good
```javascript
const protocols = dashboardData?.protocols;
const data = useMemo(() => {
  return process(protocols);
}, [protocols]);
```
