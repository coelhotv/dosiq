# AP-134: CSS Breakpoint sem Descontar Sidebar — Overflow em Tablet

## Context
Sub-agente definiu breakpoints de grid 2-col e layouts row em `1024px` sem considerar que a sidebar fixa ocupa 256px do viewport.

## Anti-Pattern
```css
/* ❌ ERRADO — ignora sidebar */
@media (min-width: 1024px) {
  .cronograma-doses { grid-template-columns: 1fr 1fr; }
  .treatments-topbar { flex-direction: row; }
}
```

Em iPad Mini (1024×768), conteúdo útil = 1024 - 256 (sidebar) - 32 (padding) ≈ 736px. Colunas de ~368px são insuficientes para cards com `padding: 2rem`.

## Consequências
- PriorityDoseCard sangrando além do viewport em 1024px
- Barra de busca de tratamentos vazando da tela
- Layout quebrado em iPad Mini / tablet landscape

## Correct Approach
```css
/* ✅ CORRETO — ajustado para conteúdo real */
/* Grids que precisam de colunas largas: 1280px+ */
@media (min-width: 1280px) {
  .cronograma-doses { grid-template-columns: 1fr 1fr; }
  .treatments-topbar { flex-direction: row; }
}

/* Busca responsiva, não fixed width */
.treatments-topbar .search-bar {
  flex: 1 1 28rem;
  max-width: 28rem; /* ← responsivo, não 0 0 28rem */
}
```

## Regra Geral
- 1024px viewport → ~464-768px conteúdo real (depende de padding)
- 1280px viewport → ~720-1000px conteúdo real
- Layouts 2-col com cards > 280px cada → usar `min-width: 1280px`
- Grid principal do dashboard pode usar 1024px (colunas flexíveis)
