# AP-241 — Mapeamento parcial à mão diverge do mapper canônico (drift de campo)

**Categoria:** react_and_ui · **Detectado:** smoke 037 (2026-06-23) · **Família:** AP-214 (campo dropado silencioso), R-235/R-279 (canônico antes de inline)

## Sintoma

Ao selecionar um medicamento da base ANVISA na busca da aba **Tratamentos**
(`AnvisaSearchBar`), o `TreatmentWizard` abria pré-preenchido — mas o campo
**laboratório** vinha **vazio** para medicamentos **não-genéricos** (que têm
`laboratory` na base). O mesmo autocomplete dentro do **form de medicines isolado**
preenchia o laboratório corretamente.

## Causa

`AnvisaSearchBar.handleSelect` montava o payload do wizard **à mão**, com apenas 3
campos:

```js
onOpenWizard({
  name: toTitleCase(anvisaMedicine.name),
  active_ingredient: ... ,
  therapeutic_class: ... ,
})
// faltava: laboratory, regulatory_category
```

O path correto (form de medicines) usa o mapper canônico
`formatSelectedMedicine` (`_medicineFormUtils.js`), que mapeia **todos** os campos
(incl. `laboratory` e `regulatory_category` normalizado). Os dois mapeamentos
divergiram: o wizard ficou com um subconjunto, dropando campos sem erro.

Por que escapou ao teste: o teste unitário exercitava o path do form (mapper
canônico), nunca o path do wizard (mapper parcial).

## Fix

Reusar o mapper canônico nos dois pontos — paridade por construção:

```js
import { formatSelectedMedicine } from '@medications/components/_medicineFormUtils'
// ...
onOpenWizard(formatSelectedMedicine(anvisaMedicine))
```

+ teste de regressão (`AnvisaSearchBar.test.jsx`) afirmando que o payload do
`onOpenWizard` inclui `laboratory` e `regulatory_category` para um não-genérico.

## Guard

- Ao pré-preencher um form/wizard a partir de uma entidade de origem, **nunca**
  remontar o objeto campo-a-campo à mão se já existe um mapper canônico — reusar.
- Se há N pontos que mapeiam a mesma origem → o mapeamento é uma função única
  compartilhada (R-235). Divergência = campo dropado em silêncio.
- Smoke: exercitar **todos** os pontos de entrada (form isolado E wizard), não só um.
