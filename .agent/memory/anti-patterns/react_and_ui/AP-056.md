# [AP-056] Unstable Fetcher Loop

## Contexto
Ocorre quando um hook disparador de dados (como SWR ou useEffect) depende de uma função definida inline ou sem memorização.

## Problema
Dispara centenas de requisições por segundo até travar o navegador ou exceder a quota da API (Supabase/Vercel).

## Como evitar
Sempre use `useCallback` para funções de fetch e garanta que as dependências do `useCallback` sejam estáveis.
