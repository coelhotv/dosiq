# AP-121: Inline Styles for Design System Tokens

## Problem
Using the `style` attribute in React components to define margins, paddings, or cursors that should be handled by the CSS design system.

## Consequence
- Breaks consistency: Each component might have slightly different spacing.
- Hard to maintain: Changing a spacing token requires finding every inline instance.
- Violates A11y/Theming: Inline styles are harder to override via themes or accessibility tools.

## Solution
Use utility classes defined in `index.css` or the component's CSS file (e.g., `.sr-icon-ml`, `.sr-btn-primary`).
