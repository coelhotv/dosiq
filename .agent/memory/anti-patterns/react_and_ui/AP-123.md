# AP-123: Disconnected "Back" Navigation Flow

## Problem
Implementing a "Back" button that always redirects to a fixed "Home" or "Dashboard" page, regardless of where the user actually came from.

## Consequence
- Poor UX: Users lose their navigation context (e.g., coming from Profile -> Settings and being sent to Dashboard on "Back").
- Frustration: Patients may have to re-navigate multiple steps to return to their previous view.

## Solution
Use a state-aware or context-aware back navigation (e.g., passing a `from` prop or using browser history if appropriate for the PWA flow).
