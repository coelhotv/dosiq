# AP-132: Unprotected String Prototypes on Form Data

**Sintoma**: Crash `TypeError: Cannot read properties of undefined (reading 'trim')` ao salvar ou renderizar formulários.

## Descrição
Chamar métodos de protótipo de string como `.trim()`, `.toLowerCase()` ou `.replace()` diretamente em campos de `formData` sem garantir que o campo foi inicializado ou sem usar optional chaining.

## Como Evitar
1.  **Optional Chaining**: Use `formData.field?.trim()`.
2.  **Fallback na Inicialização**: Garanta que todos os campos no `initialState` sejam ao menos uma string vazia `''`.
3.  **Logical OR**: Use `(formData.field || '').trim()`.

## Exemplo Real (Dosiq Crash)
O componente `StockForm` quebrava ao tentar computar o `effectiveLaboratory` porque `formData.laboratory` não estava garantido como string antes do `.trim()`.

```javascript
// CORRETO
const effective = formData.laboratory?.trim() || null

// INCORRETO
const effective = formData.laboratory.trim() || null
```
