# AP-077 — Callback Data HH:MM Split Destructuring

`callback_data` do Telegram tem limite de 64 bytes e usa `:` como delimitador interno (ex: `takelist:misc:23:00`). Destructuring direto com `split(':')` quebra quando o horário contém `:`.

## Padrão incorreto

```js
// "takelist:misc:23:00".split(':') → ['takelist', 'misc', '23', '00']
const [_, type, hhmm] = data.split(':')
// hhmm = '23'  ← ERRADO (truncado)
```

## Padrão correto

```js
const parts = data.split(':')
const type = parts[1]
const hhmm = parts.slice(2).join(':')  // → '23:00'  ✓
```

**Why:** `HH:MM` sempre usa `:` como separador. Qualquer campo que venha depois na string de callback_data precisa de `slice(N).join(':')` em vez de destructuring posicional.

**How to apply:** Em todo handler de callback Telegram que parseia `hhmm` ou qualquer campo time-like: usar `parts.slice(N).join(':')`. Verificar especialmente `handleTakeList`, `handleTakePlan`, `handleSnooze` quando implementado.
