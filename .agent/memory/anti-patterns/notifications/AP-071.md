# [AP-071] Timezone-dependent logic in notifications without UTC conversion

**Status:** active · **Layer:** warm · **Domain:** notifications
**Reconciliado:** 2026-05-31 (D5 — detail file recriado a partir do índice; arquivo original ausente/perdido)

## Sintoma
Lógica de agendamento/disparo de notificação dependente de fuso sem converter para UTC
primeiro → janelas e horários disparam na hora errada conforme o fuso do servidor/cliente.

## Regra
Converter datas locais para UTC ANTES de comparar/filtrar (R-131). Em queries de coluna
timestamptz, usar UTC real — ver [[AP-194]] (getNow().toISOString() desloca o instante).
