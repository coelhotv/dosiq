# AP-165 — Modal RN sem `statusBarTranslucent` no Android < 8 deixa parent stack vazar

**Sintoma** (Android API 24 / Android 7): bottom sheet abre mas:
- Overlay semitransparente NÃO cobre o topo da view (gap visível)
- Inputs do form parent ATRÁS do sheet aparecem por cima do conteúdo do sheet
- Botões de ação do sheet ficam cortados pela bottom tab bar do navigator parent

**Root cause**: `<Modal>` do RN no Android sem `statusBarTranslucent={true}` herda o layout do screen pai do navigator — não estabelece overlay de window stack inteiro. Inputs ficam em z-index acima do overlay; tab bar do parent renderiza por cima.

**Por que perigoso**: bug invisível em iOS + Android modernos (que tratam Modal como window root nativamente). Só aparece em API 24 — fácil de não pegar no smoke se PO só testa devices modernos.

**Fix unificado** (aplicado em TODOS os sheets de Fase 1+2):

```jsx
<Modal
  visible={open}
  transparent
  animationType="slide"
  onRequestClose={onClose}
  statusBarTranslucent  // ← key fix
>
  <View style={styles.root}>
    {Platform.OS === 'android' ? (
      <View style={{ height: StatusBar.currentHeight ?? 0 }} />
    ) : null}
    <Pressable style={styles.backdrop} onPress={onClose} />
    <SafeAreaView edges={['bottom']} style={styles.sheet}>
      {/* conteúdo */}
    </SafeAreaView>
  </View>
</Modal>
```

3 componentes do fix: `statusBarTranslucent` + spacer manual `StatusBar.currentHeight` no topo (Android only) + `SafeAreaView edges=['bottom']` no sheet container (gesture bar moderno).

**Regra preventiva**: ver [[R-233]] — pattern obrigatório em todo novo bottom sheet mobile.
