# [AP-124] MarkdownV2 Escapes in Push Content

## Pattern
Using MarkdownV2-style escapes (backslashes before reserved characters) in notification fields intended for mobile push delivery (e.g., `pushBody`).

## Impact
Mobile devices render these backslashes literally, showing content like "Olá\! Como você está\?" instead of "Olá! Como você está?". This creates a "broken" UI feel and suggests a lack of attention to platform-specific constraints.

## Detection
- Grep for `\\!` or `\\.` in files that define `pushBody`.
- Review PRs adding new notification templates to ensure a clear distinction between `richBody` (Markdown) and `pushBody` (Plain Text).

## Fix
Remove all backslash escapes from the affected string. If the string is shared with a Markdown template, use a helper or `.replace(/\\/g, '')` to sanitize it for push.

## Example Incident
- **Wave 11**: Notification revamp introduced `pushBody` to `daily_digest` and `adherence_report` but included MarkdownV2 escapes inherited from the rich template logic. Fixed in PR #517.
