# AP-177 — VirtualizedList (FlatList) aninhada em ScrollView mesma orientação

**Classe:** mobile_and_platform · **Status:** warm · **Trigger count:** 1

## Sintoma
"VirtualizedLists should never be nested inside plain ScrollViews with the same
orientation" — no iOS dispara a cada keystroke em overlay de autocomplete que usa
FlatList dentro de form com ScrollView.

## Causa
FlatList é VirtualizedList; aninhar na mesma orientação quebra a virtualização e
o RN avisa por render.

## Correção
Em overlays/listas curtas (ex.: dropdown de autocomplete), usar **ScrollView
plano + `.map()`** com `key` por item. RN só barra VirtualizedList aninhada;
ScrollView plano é permitido (`keyboardShouldPersistTaps`, `nestedScrollEnabled`,
`maxHeight` para scroll interno).

## Onde aplicar
Listas curtas/finitas dentro de ScrollView. Listas longas → manter FlatList e
não aninhar (mover para fora do ScrollView).
