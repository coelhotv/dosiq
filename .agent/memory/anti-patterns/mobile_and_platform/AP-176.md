# AP-176 — Dois NavigationContainer com a mesma ref → "navigation hasn't been initialized"

**Classe:** mobile_and_platform · **Status:** warm · **Trigger count:** 1

## Sintoma
Ao alternar entre dois `<NavigationContainer ref={navigationRef}>` (ex.: wizard
de onboarding vs app), `navigationRef.navigate(...)` lança
"navigation hasn't been initialized yet".

## Causa
Cada NavigationContainer registra/desregistra a ref ao montar/desmontar. Trocar
de container desmonta um e monta outro; durante a transição a ref aponta para um
container não-inicializado. Push deep-link no cold start agrava (race).

## Correção
**Um único** NavigationContainer com filho condicional:
```jsx
<NavigationContainer ref={navigationRef}>
  {needsOnboarding ? <OnboardingNavigator/> : <Stack.Navigator>...</Stack.Navigator>}
</NavigationContainer>
```
Complemento: guardar navegação por push com `navigationRef.isReady?.()` + retry
curto no cold start.

## Onde aplicar
Qualquer gate que alterna árvores de navegação compartilhando a mesma ref.
