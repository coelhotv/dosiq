## Descrição

`Object.fromEntries(new URLSearchParams(str))` lança `"iterator method is not callable"` no Hermes (engine JS padrão do React Native/Expo). `URLSearchParams` no Hermes não implementa o protocolo iterator (`Symbol.iterator`), portanto não pode ser usado com `Object.fromEntries`, spread (`[...sp]`), ou `for...of`.

## Contexto de Ocorrência

Deep link handler de recovery de senha. URL recebida: `dosiq://auth/callback#access_token=...`. O hash (1017-1030 chars) chegava corretamente, mas o parse falhava silenciosamente com exception capturada por try/catch.

## Pattern Problemático

```javascript
// NUNCA em React Native / Hermes:
const params = Object.fromEntries(new URLSearchParams(hash))
const entries = [...new URLSearchParams(hash)]
for (const [k, v] of new URLSearchParams(hash)) { ... }
```

## Fix

```javascript
// SEMPRE: usar .get() diretamente
const sp = new URLSearchParams(hash)
const type = sp.get('type')
const accessToken = sp.get('access_token')
const refreshToken = sp.get('refresh_token')
```

## Impacto

Fluxo de recovery de senha completamente silencioso — URL chegava, hash parseado, mas `setSession` nunca chamado. App ficava em Landing sem nenhum erro visível ao usuário.
