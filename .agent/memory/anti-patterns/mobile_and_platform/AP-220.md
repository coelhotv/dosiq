## Problema

`FlatList` com `scrollEnabled={false}` dentro de um `ScrollView` externo:
1. Gera warning React Native: "VirtualizedLists should never be nested inside plain ScrollViews"
2. Desabilita a virtualização — todos os itens são renderizados de uma vez (sem lazy rendering)
3. Sem scroll próprio + sem virtualização = overhead de FlatList sem nenhum benefício

## Root Cause

`FlatList` depende do seu próprio scroll para medir a janela de virtualização. Com `scrollEnabled=false`, ela não consegue determinar quais itens estão visíveis → renderiza tudo. O warning é explícito do React Native sobre este anti-pattern.

## Fix

Para listas pequenas (≤ ~50 itens) aninhadas em ScrollView, substituir por `View + .map()`:

```js
// ERRADO:
<FlatList
  data={items}
  keyExtractor={(item, i) => item.id ?? i.toString()}
  renderItem={({ item }) => <ItemCard item={item} />}
  scrollEnabled={false}
/>

// CORRETO:
<View>
  {items.map((item, index) => (
    <React.Fragment key={item.id ?? index.toString()}>
      <ItemCard item={item} />
    </React.Fragment>
  ))}
</View>
```

Para listas grandes (> 50 itens): reestruturar o layout para que a FlatList seja o ScrollView raiz, usando `ListHeaderComponent` e `ListFooterComponent` para o conteúdo que estava no ScrollView externo.

## How to apply

Antes de usar `FlatList scrollEnabled=false` dentro de qualquer `ScrollView`:
- Avaliar tamanho máximo realista da lista
- ≤ 50 itens → `View + .map()` diretamente
- > 50 itens → refatorar para FlatList como scroll raiz
