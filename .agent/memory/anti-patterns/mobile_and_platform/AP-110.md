# AP-110: The Stale Cache Ghost

Confiar exclusivamente no filtro de data feito pelo backend/serviço ao consumir dados que ficarão em cache offline.

## O Sintoma
O usuário acorda, abre o app (offline) e ainda vê tratamentos que terminaram ontem, porque o snapshot do AsyncStorage ainda contém esses registros e o "dia" virou para o cliente mas não para o cache.

## A Solução
Implementar a Regra **R-185**: Aplicar filtragem temporal redundante na camada de UI (hooks) para garantir que apenas dados válidos para o `getTodayLocal()` atual sejam renderizados.
