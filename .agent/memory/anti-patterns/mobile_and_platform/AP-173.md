# AP-173 — signOut() escopo global trava o logout (iOS sim / Workbox)

**Classe:** mobile_and_platform · **Status:** warm · **Trigger count:** 1

## Sintoma
`supabase.auth.signOut()` (escopo global, default) pendura no simulador iOS e
pode ser bloqueado pelo Workbox na web (PWA) — usuário toca "Sair", confirma o
alerta e **nada acontece** (permanece logado, sem erro).

## Causa
O escopo global tenta revogar a sessão no servidor (network round-trip). Em
ambientes onde a request não resolve (sim sem rede confiável, SW interceptando),
a Promise não resolve e o fluxo de logout fica preso.

## Correção
Usar escopo local — limpa a sessão no device sem depender do servidor:
```js
await supabase.auth.signOut({ scope: 'local' })
```
Mobile: `authService.signOut` + `profileService.logoutUser` usam `scope:'local'`.
Web: cleanup de localStorage + reload (ver feedback Workbox/Supabase logout).

## Onde aplicar
Qualquer fluxo de logout (mobile e web PWA).
