# AP-174 — Bottom sheet/Modal RN + teclado + tab bar (Android API 24) corta campos/botões

**Classe:** mobile_and_platform · **Status:** warm · **Trigger count:** 1

## Sintoma
Em fluxo destrutivo com input (ex.: excluir conta — digitar "EXCLUIR" + senha)
dentro de bottom sheet/Modal: ao abrir o teclado o campo fica por baixo dele;
ao fechar, o sheet encolhe; botões de ação ficam cortados sob a barra de
navegação. Android 7 (API 24, tela pequena) não permite rolar até o campo.

## Causa
`KeyboardAvoidingView` dentro de `Modal` no Android não mede corretamente;
`statusBarTranslucent` quebra a medição do KAV; `SafeAreaView` dentro de Modal
mede errado. 4 tentativas (behavior do KAV, listeners manuais + marginBottom,
maxHeight dinâmico, scroll único) falharam no API 24.

## Correção
Fluxos destrutivos / com input pesado → **tela cheia** (Screen do navigator),
não bottom sheet. Padrão validado (StockAdjustmentScreen): header fora do KAV,
`KeyboardAvoidingView` flex `behavior` padding(iOS)/undefined(Android) envolvendo
ScrollView + FormActions, `SafeAreaView edges={['top','bottom']}`.

## Onde aplicar
Bottom sheets com TextInput em Android antigo. Logout (sem input) pode seguir
bottom sheet.
