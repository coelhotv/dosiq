# AP-112 — 1-push-per-protocol notification spam

## Sintoma

Usuário recebe N notificações simultâneas (uma por protocolo agendado no mesmo minuto),
causando spam no celular e ausência de contexto de tratamento.

## Causa

Loop `for (const dose of dosesNow)` chama `dispatcher.dispatch()` uma vez por protocolo,
sem agrupar doses do mesmo horário.

```js
// ERRADO — 1 push por protocolo
for (const dose of dosesNow) {
  await dispatcher.dispatch({ userId, kind: 'dose_reminder', data: { protocolId: dose.id, ... } })
}
```

## Correção

Chamar `partitionDoses()` antes do loop, e despachar 1 push por bloco:

```js
// CORRETO — 1 push por bloco semântico
const blocks = partitionDoses(dosesNow)
for (const block of blocks) {
  await dispatcher.dispatch({ userId, kind: block.kind, data: { ...block } })
}
```

## Regra associada

**R-191** — Semantic Dose Notification Grouping

**Why:** N notificações no mesmo minuto são percebidas como spam,
reduzem a aderência às notificações e perdem o contexto de plano de tratamento.
