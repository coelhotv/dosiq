# [K-091] Constraints do Alarme Nativo no iOS (vs Android)

## Contexto
O Alarme Nativo (Spec 001) tem paridade de intenção entre Android e iOS, mas o iOS
impõe limites de plataforma que mudam a experiência. Referência para A2 e v2.

## Diferenças-chave

| Capacidade | Android | iOS |
|-----------|---------|-----|
| Takeover full-screen na lock screen | Sim (full-screen intent) | **Não existe** — tap na notif abre o app → tela cheia |
| Furar DND/Focus | `bypassDnd` no canal | `interruptionLevel:'timeSensitive'` (auto-concedido) |
| Furar mudo físico (silencioso total) | `bypassDnd` cobre | **Só Critical Alerts** (entitlement aprovado pela Apple) |
| Som em loop até agir | `loopSound`+`ongoing` | Não nativo (toca 1×, ~30s); loop só com Critical |
| Botões de ação | array `actions` no payload | `setNotificationCategories` + `categoryId` ([[R-257]]) |
| Som com app em foreground | toca | precisa `foregroundPresentationOptions` |

## Níveis de interrupção iOS (escada)
1. **timeSensitive** (atual): fura Focus/DND, auto-concedido. Entitlement
   `com.apple.developer.usernotifications.time-sensitive` declarado. **Não** fura
   mudo físico.
2. **critical** (futuro/v2): fura mudo físico/silencioso total. Exige entitlement
   `...critical-alerts` **aprovado** via formulário Apple (em avaliação; justificativa
   = app de medicação). Promover = trocar `IOS_INTERRUPTION_LEVEL`→`'critical'` +
   `critical:true` no payload + declarar o entitlement ([[R-259]]). Documentado inline.

## Armadilhas resolvidas
- **EAS desativa o entitlement**: declarar no `.entitlements` nativo, não só no
  `app.config` ([[R-259]]).
- **Ações na lock screen falham** (Apple Watch): SecureStore precisa de
  `AFTER_FIRST_UNLOCK` ([[R-256]]) p/ ler a sessão travado.
- **`openAlarmScreen` não abria no iOS**: filtrava por `android.channelId`; iOS
  identifica por `ios.categoryId`.
- **Som mudo em foreground**: `foregroundPresentationOptions` ([[R-257]]).

## Validação de som (.wav)
iOS exige Linear PCM/IMA4/µLaw, ≤30s. Conferir: `afinfo alarm_dose.wav`. O
plugin `expo-notifications` `sounds` copia p/ o bundle iOS + `res/raw` Android.
